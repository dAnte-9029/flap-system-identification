# 不区分train/validation的片段时长与间隔统计

本次只对已有筛选结果作合并描述，不按train/validation统计、不重新划分或训练。旧分区元数据仍保留用于追溯；未访问新的原始日志、sealed test或reserved evaluation。两个范围分别为全部初筛与此前首轮同配置最终子集，后者包含在前者中，不能相加。

## 窗口与连续片段的区别

现有窗口覆盖最早历史执行命令到最后预测目标，实际时间跨度1.52秒，常见起点间隔0.2秒。因此相邻窗口大量重叠；窗口数乘1.52秒会重复统计同一段飞行。这里把同log、同原质量/模式片段内时间覆盖相连的窗口取并集，按首末时间戳的实际经过时间计时，不额外增加最后一个20ms采样格。不同log不合并，模式/质量边界不跨越。

## 同一日志内相邻片段间隔

间隔定义为“下一段开始−上一段结束”。只统计同log内部，排除首段之前、末段之后及跨log的日期间隔。

| 指标 | 全部初筛 | 同配置子集 |
|---|---:|---:|
| 间隔个数 | 155 | 52 |
| 间隔总时长 | 210.06秒 | 63.92秒 |
| 平均 | 1.36秒 | 1.23秒 |
| 最小 | 1.02秒 | 0.08秒 |
| P25 | 1.08秒 | 1.02秒 |
| P50 | 1.12秒 | 1.08秒 |
| P75 | 1.18秒 | 1.15秒 |
| P90 | 1.20秒 | 1.25秒 |
| P95 | 1.39秒 | 1.89秒 |
| 最大 | 12.64秒 | 12.10秒 |
| ≤2秒 | 149/155 | 49/52 |

全部初筛155个间隔中141个的两侧模式不同。筛选器在每个模式/质量分段两端各裁掉0.5秒，再叠加窗口起点网格的尾部余量，因此大量间隔约1.0–1.2秒。这主要是筛选产生的间隔，不是“原始日志缺了1秒”的证明。

同配置子集多出12处同原始片段内部的断开，来自后续manual参考有效性筛选；间隔可以很短。时间分段并不自动消除共享飞行条件和时间相关性。
