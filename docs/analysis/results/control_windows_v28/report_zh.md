- servo0 = 0.5×torque_pitch − torque_roll/(2×0.5500000119)
- servo1 = 0.5×torque_pitch + torque_roll/(2×0.5500000119)
- servo2 = torque_yaw；motor0 = thrust_x

之后按舵机[-1,1]/电机[0,1]限幅。这里是归一化控制需求，不是已测N、N·m。方程来自源码/参数，没有用响应拟合系数。
