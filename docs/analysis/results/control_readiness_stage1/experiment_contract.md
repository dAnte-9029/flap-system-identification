# 控制可用性实验契约 v0.1

状态：对象、隔离规则与评价协议冻结；绝对性能预算未冻结，因此禁止据此宣布“控制可用”。本文件不授权打开封存测试集。

1. 模型参照固定为 model_references.json 的 S0/S1。新九月训练采用注册数据并建立同数据匹配参考，不能复用八月成绩充当九月对照。
2. 控制器参照固定为 e624 的 A（FLAP_SLOW_EN=0）与 B（=1、ADAPT=1、CAP=0.03），以每份日志参数快照和模式段为准。首次优先验证 A；B 另外回放积分转移状态，禁止混合计分。log_0 只有一次，不能由其独立建立跨飞行重复性结论。
3. 首任务为已记录前飞/航线工况的姿态—角速度响应，俯仰优先。第二阶段先在训练分区定义有效飞行、模式稳定、估计器无重置、相位有效、必要信号无大于 0.05 s 间隔的候选规则；低频空速/分配器反馈另记录数据龄，不强套 0.05 s 阈值。规则冻结后再用于验证集，报告全部符合与被排除片段及原因。模式切换附近不能跨界取历史/预测窗口。
4. 在读取模型预测前，由训练分区确定并记录工况、激励幅度和其他通道耦合阈值；用验证分区判断规则可迁移性。若不能找到独立俯仰输入证据，结论为“响应未充分约束”，转入补辨识数据设计，不能靠放宽规则筛选成功案例。
5. 预测时域固定 0.1/0.2/0.5/1 s，0.5/1 s 为主。真实历史仅用于初始化，后续完整自主递推。姿态用四元数测地误差并报告任务轴角度，角速度逐轴 rad/s，速度逐轴 m/s，位置 m；报告每次飞行 RMSE、P95、失败数，再做等飞行权重汇总。置信区间按整条飞行重采样，不能把重叠窗口当独立样本。3–5 s 仅作诊断。
6. 输入响应检查方向、增益、延迟、上升/衰减过程；模型内扰动属于合理性检查，不等于真实反事实证据。简单运动学外推和同数据低阶输入—输出模型作为可实现对照；不得以重新走完整灰箱研究路线代替本任务。
7. 先做记录状态/设定值驱动的控制器输出回放，再做只读取模拟状态的闭环。分别报告姿态/角速度跟踪、超调、持续振荡、控制量变化率、输出饱和、裁剪/数值失败；历史暖启动与任意状态冷启动分开。
8. 绝对预算待补：俯仰角、俯仰角速度、速度在 0.5/1 s 的 RMSE/P95 上限；控制器回放输出误差上限；允许的增益/延迟偏差；可检出的最小控制收益。依据有效机动幅度、记录分辨率、重复飞行差异和拟优化收益提出数值，在新候选训练/选型前保存下一版契约；不能从候选误差反向制定及格线，也不自动沿用 5°/0.5 m/s。
9. 进入闭环设计需同时通过上述预算、跨飞行一致性、输入响应和无未来状态泄漏检查。缺预算或缺证据均保持未通过。实机部署与控制器比较属于后续阶段，本次未执行。
