# v22：407个原训练窗口的输入可恢复性与覆盖审计

**已保留并审计全部407个窗口。手动偏航的主要限制同时包括记录稀疏和操纵覆盖不足；不能把它归结为391一个异常窗口。**274个Stabilized窗口中，未来输入段manual_yaw变化超过两个RC计数的只有4个，来自2个飞行。133个Mission窗口在现有模型合同中不使用manual_yaw，不能因手动日志稀疏而被归为无效数据。

本轮没有重训、改输入、删除窗口、修改评价门槛或访问开发验证/sealed/reserved。保留A1600和v18未晋升结论，也未证明必须补飞。

## 范围与统计口径

- 原train父窗口407个，5个九月飞行；原支撑互不重叠，总时长618.64s（10分18.64秒），每窗1.52s。Stabilized为416.48s，Mission为202.16s。这不是407次独立随机试验，也不是50Hz独立样本数。
- 每窗重核原支撑`origin−26..origin+50`共77点，未来计划输入仍为`origin..origin+49`共50点。RC补充证据检查完整1.52s，不能和仅未来0–0.98s的变化幅值混用。
- 只按输入、时间戳、模式和已有v19参考活动层描述；没有读取模型预测误差或用未来响应选择样本。已有层来自各折fit飞行，未重新拟合阈值。
- 手动消息选择要求publication和sample均不晚于查询时刻；年龄取两者年龄中较大者。无sample timestamp的rate/attitude参考只能报告发布年龄，不能解释为物理采样或执行时延。
- “一个RC计数”采用两侧标定中较大的归一化步长。本批5飞行均为1/420≈0.002381；≤1、1–2、>2计数仅用于区分量化级变化与较大变化，不是激励充分性或数据淘汰阈值。所有连续值和完整窗口清单一并交付。
- 聚合年龄为所有适用窗口各50个未来点的池化分位数，因此每个窗口等权，飞行按窗口数加权；不将其称为飞行等权或独立样本置信区间。

## RC补充证据揭示什么

完整支撑共1236条RC记录，其中834条属于274个Stabilized窗口且满足有效RC、正确通道、manual来源为RC、采样时间顺序正确、manual控制开启等条件。每个Stabilized窗口都有至少一条这样的证据。

在4个窗口中，共6条RC记录与当时最近已记录manual值差异超过两个计数。它们不是同一时刻的传感器矛盾，而是相隔一段时间的观测，揭示稀疏保持序列未表达的新输入。

| 窗口 | RC相对预测起点时刻 | 差异所在部分 | 说明 |
|---|---|---|---|
| 46 | +0.833s | 未来输入段 | 差异约−0.1571 |
| 328 | −0.221s | 历史段 | 差异约−0.0810，不能计作未来输入丢失的证据 |
| 391 | −0.004、+0.498、+0.999s | 历史、未来输入、末端响应附近 | 后两个差异约−0.3286、+0.2976；+0.999s已晚于最后一个计划输入点+0.98s |
| 392 | −0.243s | 历史段 | 差异约+0.5452；未来幅值仅0.002381，但完整支撑幅值0.547619 |

392说明“未来变化小”不等于整个历史上下文没有操纵，不能仅按未来幅值删去恢复过程。窗口17未被稀疏RC记录捕获到大差异，也不能因此认证其完整参考可恢复。

RC约每500ms记录一次，manual约每200ms记录一次。没有观测到差异只能表示现有稀疏证据未发现，不能证明中间信号恒定；插值、平移或清零均不能创造高频真值。不同来源消息的差异也不能直接当作控制器采用新输入的准确时间。

## 能支持什么，不能据此声称什么

1. **现有数据仍值得保留用于动力学研究。**Mission具有较密的姿态/角速度参考和执行命令；Stabilized的大部分窗口可提供其他通道的变化与运行背景。不能因为manual稀疏就丢弃整个飞行或模式。
2. **当前不能认证快速手动偏航参考驱动的模型。**较大未来变化仅4窗、2个飞行，且部分窗口已有保持遗漏证据；数量、方向、状态匹配和输入独立性均不足以仅凭本轮审计确认偏航控制能力。
3. **也不能据此认证低频或“平稳”窗口已经可控。**本轮没有测量参考频带、舵机动态、真实反事实响应或新控制器闭环性能。log_18的持续q偏差没有被此次manual审计解释。

下一步建议冻结一个**角速度参考驱动的对照模型**：将输入边界明确改为“预定机体角速度参考＋推力参考→固定PX4角速度内环＋飞机”，沿用原407窗口、5折×3种子和相同训练预算，保留原模型作参照。先核验该新合同的历史/未来索引与推力来源，再执行训练和相同状态验收；本轮尚未更换合同或启动该对照。

它可以利用约50Hz的已记录参考，但该参考在旧日志中由姿态反馈生成。离线用未来日志rate参考得到的收益，只能评价新的条件预测任务，**不能当作原姿态参考模型的自主预测收益或真实干预舵效**。若以后接回姿态参考外环，必须由模拟状态运行同一姿态控制器产生rate参考，而不是继续喂未来日志。新控制用途仍需独立响应证据和闭环验收。
