# v24：历史控制器状态审计与冻结对照方案

**已核验并准备407个窗口的历史控制器输入，形状为407×26×8。**三轴积分状态、三轴增益压缩及两组记录年龄均可因果取得；未删除窗口，也未加入预测起点之后的控制器状态。本轮完成审计、数据准备和对照设计，尚未启动新训练。保留A1600及v23未晋升结论。

## 哪些记录可用

| 内容 | 来源及含义 | 本轮用途 |
|---|---|---|
| 三轴积分状态 | rate_ctrl_status：本次积分更新后的状态 | 历史编码输入 |
| 三轴增益压缩 | gain_compression.compression_gains：本次压缩更新后发布的增益 | 历史编码输入 |
| 两组记录年龄 | 查询时刻减各自最近发布时刻 | 历史编码输入 |
| PID分项 | rate_ctrl_terms：本次输出使用的P/I/D/FF和 | 语义与时序审计，不进入本次新增特征 |
| 空速缩放 | 未直接记录；可在严格同步条件下从PID项反推 | 诊断保留，不进入首个对照 |
| 增益压缩的谱滤波量 | gain_compression还记录部分滤波状态 | 暂不加入首个对照，避免同时扩展更多状态 |

两种积分记录的区别来自精确固件源码：`RateControl::update()`先使用当前积分计算输出、填充`terms.i_term`，随后更新积分；后续`getRateControlStatus()`再读取更新后的积分。二者相差一个积分更新，不能混成同一时刻同一语义的量。

增益压缩也有先后次序：本次控制输出先使用`getGains()`，之后调用`update()`，后者约每100ms发布一次增益。所以日志增益是过去发布的内部状态观测，不等同于任意时刻实际乘到力矩上的精确增益。保留其记录年龄，不向未来回填。

源码：[积分更新顺序](source/rate_control.cpp)、[压缩更新与发布](source/gain_compression.cpp)、[固定翼调用链](source/FixedwingRateControl.cpp)、[空速滤波器定义](source/FixedwingRateControl.hpp)、[AlphaFilter](source/AlphaFilter.hpp)。均按日志固件c9af571575af33d5403fbb479256848797c801e2导出，并记录blob及SHA256；不是当前分支代码的猜测。

## 历史记录质量和覆盖

所有原407个train窗口保留，每窗26个过去时刻，共10582点；5个原train飞行，mode3/15范围继承v23。没有加载开发验证、sealed或reserved，没有用预测误差筛选数据。

| 历史量 | 记录年龄中位数 | P95 | 最大 |
|---|---:|---:|---:|
| 更新后积分 | 16.088ms | 19.762ms | 21.622ms |
| 增益压缩 | 51.023ms | 96.693ms | 104.612ms |

这些均为**发布年龄**：两个状态话题没有独立timestamp_sample，不能将该数值称为传感器、舵机或飞机时延。重复保持仍保留，未插值制造高频观测。

观测积分p/q/r范围分别约为[−0.2,0.2]、[−0.4,0.4]、[−0.2,0.2]；增益压缩p/q/r范围约为[0.378,0.837]、[0.445,0.865]、[0.793,0.991]。压缩并非始终等于1，不能在控制链重放中无条件忽略。

五飞行均启用FW_GC_EN、FW_ARSP_SCALE_EN和FW_USE_AIRSPD，增益压缩下界0.3。在10215条被历史查询使用的PID分项记录中，9969条能找到同周期时序相容的更新后积分消息：取terms之后、下一条terms之前且间隔不超过1ms的第一条status，并检查一对一。实际发布间隔中位4μs、最大42μs。该配对是时序一致性检查，status没有独立采样时间，不能当成精确sample标记。

这些配对的更新前后积分差值RMS约为p=0.000133、q=0.000135、r=0.000052；最大绝对差约0.000751、0.000604、0.000336。差值符合“不同积分更新阶段”的语义，不是发现两份日志互相矛盾。未配上的记录不用于该检查，原窗口不因此删除。

## 空速缩放能否恢复

源码中空速缩放基于一个时间常数1s的滤波空速，随后经过失速空速下限；另有有效性/超时与配平空速回退路径。因此，简单计算`配平空速 / 原始空速`不是该内部状态的完整恢复。

本轮采用不拟合时延的代数诊断。只匹配`rate_ctrl_terms`与`vehicle_angular_velocity`完全相同的timestamp_sample，在本批非VTOL、参数固定且P/FF增益为正的条件下：

\[
\omega_{sp,used}=P_{term}/K_P+\omega,
\qquad
s=K_{FF}\omega_{sp,used}/FF_{term}.
\]

式中s是控制器空速缩放。它利用控制器实际使用的角速度参考关系，未用异步保持的rate参考代替。仅在对应轴的|FF_term|≥0.001且比值为正、有限时计算；预先固定选择|FF_term|最大的有效轴，保留其他轴用于交叉核对。

- 10215条历史PID分项中，9796条有精确陀螺仪sample配对，全部得到至少一个有效缩放估计；未配对部分不外推为已验证。
- 9788条有至少两个有效轴，多轴比值极差中位1.72e−7、P95=1.47e−6、最大3.38e−5，支持源码公式和同步关系的一致性。
- 反推缩放范围约0.626–2.667；与同时可获得原始空速直接构造的未滤波代理，绝对差中位0.0566、P95=0.2173、最大1.6250。差异包含滤波、时序及有效性处理的影响，不能全部归因于某一个机制。

这项诊断不是独立传感器真值，也没有恢复滤波器与压缩器的全部隐藏状态。**首个训练对照只采用直接记录的积分/压缩状态与年龄，反推缩放不进入训练。**这样可以先检验直接历史观测这一组信息，避免同时依赖代数反推覆盖、分母条件和重新滤波初始化。

## 已冻结的下一轮对照

详见[training_protocol.json](training_protocol.json)。两组都使用相同扩展结构：GRU64历史编码器输入从25变为33，增加1536个参数，总计41606；递推单元、输出头、导数限制、相位处理不变。

| 对照组 | 新增8列在历史编码器中的输入 | 目的 |
|---|---|---|
| zero_history_control | 归一化之后置零 | 相同结构和参数规模的对照 |
| observed_history_control | 真实、因果取得的归一化历史状态 | 检验新增历史观测块的收益 |

两组共享原v23初始化的所有既有权重，新增编码器列均从0开始；复用相同1600×32抽样、折划分、优化器与完整1秒损失。每组5折×3种子，共30次1600步训练。两组都重新训练；冻结v23结果只作附加参照，不能仅将扩展模型与旧结构对比后把差异都归为新信息。

主门槛为相对zero组的q完整1秒OOF波形RMSE平均改善≥5%、3个种子均改善、至少4/5飞行改善；p/r和速度/姿态保留v23的5%保护项与原0.5秒绝对精度检查。固定最终检查点，不按结果选窗口、种子或训练步数。该试验只能检验整个历史观测块，不能单独证明积分、压缩或年龄各自的因果贡献。

**本轮没有启动上述30组训练。**下一步是实现这个只扩展历史编码器的配对模型，完成零输入一致性和未来消息不影响历史的检查后运行冻结对照。数值通过也不自动晋升控制用途；仍然是给定反馈生成rate参考的条件预测任务。

## 验证

3项针对性测试通过：两个来源独立因果保持与未来消息不影响历史、空速缩放代数关系及不可辨分母、归一化常量列下限。全部407张量、10582个历史点、五折归一化和原始消息保持关系独立复算通过；陀螺仪/PID分项sample时间戳唯一性已核验。源v23交付哈希、5份ULog/cache及新增产物哈希均记录，原数据和模型未修改。

这一步确认了可以加入哪些历史信息，没有证明它们就是q误差的原因，也没有完整恢复PX4控制器内部状态。
