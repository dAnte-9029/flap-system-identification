# 快慢分离固定方案可行性验证

本报告为观测分离研究，不是物理真值或控制因果验证。仅 train/validation，无模型训练。

## 方法与边界

A 为三阶谐波加局部线性趋势的整拍等权最小二乘。B 为每拍时间加权均值趋势补偿加三阶跨拍 LSF；51拍、Q=8半格网格固定。半格网格避免强制查询翼拍边界；缺失单元不填补，三阶拟合至少8拍且两侧各2拍。趋势补偿和零均值为项目适配，不属于 Abboud 原始方法。

速度、角速度使用各自目标原生时间戳及相位；按翼拍内相邻观测插值。每拍均值与代表时间使用同一中点分区权重。每5拍留出1拍，所有拟合均排除其运动观测；评价使用A/B共同有效范围。

B零均值仅针对指定离散时间权重，不宣称连续积分精确守恒，也不保证SO(3)净旋转守恒。因果模板以最近已完整到达的51拍拟合；当前相位以截至决策时刻已到达Hall记录作局部速率外推。20ms保护不是实测延迟上界。

## 尚未完成的验证与结论限制

本实现尚未完成因果事件滞后与初始化完整数据准备耗时。事件半变化到达时间仅为描述量，不是系统辨识时延。vBx沿用冻结数据集的FRD到NED姿态R，以R转置乘NED速度；姿态与速度观测的时间差仍是该辅助诊断限制。合成阶跃当前仅评价目标拍，不能代表整个阶跃区间的最大泄漏。因果当前趋势外推已计算但尚无独立趋势误差指标。故不得据此宣布任务全部完成或建议正式标签生产。

总体结论：**证据不足**。该分类包含验证未完成的限制，不等同于方法已被否定。

## 五个问题的当前判断

1. 周期可预测性：vD、p、q有明显支持；水平速度B存在条件收益，但其总误差优势主要含局部趋势改进。r收益弱于p/q且依赖方法。
2. B改善：速度和r总误差下降，不能全部归因于LSF周期模板；本轮没有额外消融，无法唯一归因。q不存在跨split一致的胜者。
3. 非周期保留：线性扰动检验通过；局部阶跃和真实闭环事件证据仍有限，不能证明真实Slow。
4. 因果差距：计算开销小，但约51拍启动支持和通道相关信息差距存在；不能仅靠代码优化解决。
5. 下一阶段训练：证据不足，暂不推荐将本轮分离结果作为正式监督标签或直接进入GRU配对训练。
