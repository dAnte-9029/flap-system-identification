# History Length Ablation：完成核验与论文解读

核验日期：2026-09-22。9个新增训练全部成功，每个完成40+25=65 epoch、7,215次optimizer update；H26的3个既有checkpoint、predictions与evaluation直接复用。主模型仍为Standard GRU64 / H26，未改动。

## 核心结论

历史信息有稳定价值；约240 ms的H13已经获得大部分500 ms预测收益，扩展到约499 ms的H26仍有小幅平均改善。不能把这个结果写成“长历史在所有条件下均显著更好”，也不能宣称H13与H26已被证明等效。

冻结脚本的正式分类为 **Mixed**：H26在500 ms ALL四个指标均值均最低，但H13→H26的velocity/attitude/body-rate改善为2.032%/1.353%/0.544%；velocity略超预先记录的2%近似持平带，另外两项未达到Outcome A所要求的幅度。velocity及body rate仅2/3 seeds改善，不满足严格A；不支持短history明显优于H26的C。从论文叙事上接近B的“收益趋于饱和”，同时保留H26的轻微优势。原有分类规则、interpretation.json及冻结结果均未修改。

## History语义与公平性

H包括当前origin：输入state[N,H,12]、control[N,H,4]、mask[N,H]；索引t-(H-1)…t。H1仅含当前sample，命名single-sample context；它在未来rollout中仍使用recurrent transition。state与control的最后token同步于t，第一步derivative head同时接收history hidden和当前state/control，沿用既有定义，无新增off-by-one。

所有H完全复用28,293个train origins及2,582个validation origins，41个训练flight、17个验证flight（Sep7：9 flights/1,481 origins；Sep17：8 flights/1,101 origins）。H1/H5/H13只是H26数组后缀，future trajectory对象、labels、control tape、dt全部不变。原loader固定样本独立重建通过；参数量均为21,383。所有normalization、increment scales/weights、frequency setting及optimizer/schedule冻结，不重新拟合。

两个阶段seed分别为17/29、23/35、42/54；last epoch65，无validation选模。所有主指标先flight内RMSE，再flight等权平均，最后对三seed计算sampleSD(ddof=1)，不将windows视为独立样本。

## Horizon依赖：与最初预期不同

H1→H26的velocity相对改善从100 ms的68.79%、200 ms的42.94%，降为500 ms的9.62%和1 s的2.54%；attitude为25.86%、19.69%、10.56%、3.48%；body rate为20.17%、17.45%、6.95%、2.77%。因此本数据中history的相对优势更集中于早期预测，不能写成“越长预测越依赖history”。

H1 velocity在100 ms的误差高于200 ms，body-rate endpoint error也不一定随horizon单调增长。这是记录到的endpoint误差形态，时间对齐、起点、有限性与积分协议检查均通过；不能仅从该形态判定工程bug。可能的原因需要额外实验，本轮不据此改变loss或模型。1 s时H5相对H1甚至在ALL四项指标均有回退，H13的velocity也略差于H1；不存在跨全部H/horizon的严格单调律。

## 可用于论文的表述

> Historical state and control context consistently improves 500 ms prediction compared with single-sample context. Approximately 240 ms of context captures most of the observed benefit, while extending context to approximately 500 ms provides smaller, metric-dependent gains. Relative improvements are strongest at shorter prediction horizons.

以上限定于当前真实飞行日志、公开validation cohorts及冻结训练目标；不能解释为严格因果辨识、确定物理记忆时间，或长时稳定仿真证据。
