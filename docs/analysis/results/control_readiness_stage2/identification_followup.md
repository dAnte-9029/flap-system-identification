# 尾翼输入响应补证据草案

本文件是第二阶段结论的具体后续方案；未修改飞控、生成可上传任务或部署激励代码。

## A. 先完成台架上的执行器契约

1. 固定 e624 + 参数快照，分别记录 A/B；首轮辨识以 A 为参照，避免把积分转移变化和新的扰动一起引入。
2. 逐通道检查软件 left/right/rudder、PWM_MAIN1/2/5 与物理舵面的对应。记录中位、端点、反向与同向/差动动作；有可用角度测量时记录指令→舵角延迟和上升过程。没有舵角就明确识别的是“指令→机体响应”的合成动力学，不固定气动和舵机两者各自的常数。
3. 记录所有反馈变量的 publication timestamp 和 sample timestamp；控制器周期、设定值、P/I/D/FF、缩放、gain、分配器反馈、舵机/电机与 PWM 尽量同周期记录。加入控制周期序号可避免靠近时间戳猜同一周期。不能仅提高 logger 频率就认为发布频率也提高。
4. 若计划精确重建增益压缩，需要记录其初始/重置状态或完整连续输入；只记录 10 Hz gain 不足以证明高频回放完全一致。

## B. 再安排原控制器下的针对性飞行

首选明确记录的俯仰参考变化，控制器维持原稳定结构。若要验证直接舵面输入响应，必须明确定义扰动叠加点（分配前 pitch torque 或分配后 symmetric tail），两者不能混用；代码和日志都记录外生激励的开始、结束、符号、幅值与独立序号。闭环仍会反作用，分析时保留全部通道，不能把参考变化当作开环舵面阶跃。

具体数值不从当前模型反推：先由台架映射、已允许的实飞任务幅度和可辨别的测量变化确定首个幅值，再冻结；本次观察的 0.021 归一化变化阈值只用于事件筛选，不是可直接执行的飞行激励幅度。

每个事件保留至少 0.5 s 前史和 1 s 评价区间，并留足恢复时间；覆盖正负变化、多个重复飞行和相近前飞工况。采用正负交替或预先固定的平衡顺序，记录电池、载荷、风况。以整次飞行为单位预先分配开发/验证/最终评估，不把一条飞行切碎随机分区。机动幅值、周期、重复次数的最终值应在飞行实施前形成版本化试验表。

## C. 这些证据如何决定模型工作

- 如果外生输入→实测输出的符号、增益、延迟在重复飞行中一致，先用它核验现有模型的输入敏感性；不匹配时再有针对性地修时序、执行器代理或状态转移目标。
- 若实际输入变化低于噪声/扑翼周期变化，先改善实验与观测；不能靠低通后曲线更平滑宣布已经识别。
- 若只有电机→频率可靠，可先隔离验证该通道，但论文和仿真适用范围只限该证据支持的部分。
- 冻结训练/选型前的动力学误差预算需要可重复的目标任务幅度和最小预期控制收益；控制器回放误差、动态模型误差、试验重复性分别预算，不合并成一个任意阈值。
