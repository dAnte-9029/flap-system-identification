# 冻结动力学集成候选说明

本候选是研究交付，不是可上机控制器，也未获准充当RL的可信单一仿真环境。

## 组成与输入

- 基础：StandardGRU64、H26、训练K50的17/23/42三个冻结成员，原step5 `e64a1ba`派生。等权平均同一物理状态上的加速度/角加速度/频率导数，保持各成员独立隐藏状态。
- 输入：截至当前的26行状态特征与命令、mask，当前NED位置/速度、body→NED的wxyz四元数、FRD角速度、相对扑翼phase、扑频，以及候选未来归一化命令和dt。未来实测状态、舵角、空速等不得输入。
- 状态特征顺序：机体系速度3、角速度3、机体系重力3、相对当前phase的sin/cos、扑频1；命令顺序drive/left/right/rudder，分配后PWM反向前，非实测执行器位置。
- 历史时间基准沿原数据约20ms；实验原生dt，闭环组件实验固定20ms。不得把历史26步默认为任意采样频率。phase物理零位未获验证。

## 已观察到的改善

原17个validation flights、2582 origins；没有重新划分，也未打开sealed test。相对三seed原指标均值，100ms速度/姿态/角速度RMSE改善4.44%/2.39%/1.09%；200ms改善3.74%/2.69%/1.04%。两个日期、高控制变化组及全量组的48项100/200ms比较均未退化。原论文基线未被替换。

本候选增加了显式逐步接口、联合状态—动作覆盖筛查、模型分歧输出和训练残差经验误差范围，并有固定PX4组件闭环和跨模型重放证据。它可以用于离线预测研究、控制链路接口验证及控制方案的模型依赖性诊断；这些用途不等于控制性能有效。

## 明确限制

- 100/200ms是当前开发验证时域；500ms/1s仅作压力报告。没有任何实机控制或长时RL有效性声明。
- 通过support.npz的边际范围和联合最近邻检查仅表示经验覆盖，不保证未观测状态或反事实动作受支持。不能仅按单个速度/舵量范围准入。
- 支持约束下的51个闭环起点只准入23个；固定PX4俯仰反馈平均不优于保持命令。动作被限幅的比例很高，不能据此判定完整PX4性能。
- 100/200ms q误差的±2 seed标准差覆盖仅约33%，分歧不可当可靠置信区间。同架构、同训练数据可能有共同偏差。
- 经验q误差范围约±0.527/±0.533 rad/s，在原验证集覆盖约98.6%，但无反事实/分布无关保证。396个可评估动作搜索比较没有一个模型内收益超过双预测经验误差余量。
- 局部线性响应与GRU短时导数符号冲突；线性模型预测更差，不能用其符号作真值。持续舵效、执行器物理时延、未观测气流及测量链影响仍未分离。
- 历史预测残差的持续正增益修正未通过预设门槛，已否定，未纳入权重。

## 数据边界与剩余证据

仅使用已存在的trajectory_v3_september_expanded原train/validation及既有train飞行参数快照。历史项目曾评估独立测试集，因此不声称完全未知测试结果；本分支探索未读取测试集或其指标。归一化、邻域阈值、误差范围及修正系数仅用train。

距离控制可用仍缺：动作效果方向/增益/时延的独立可辨识证据，独立模型族或独立记录下可信的反事实验证，可覆盖控制需求幅度的误差界，以及完整闭环传感器/执行器链路的验证。当前交付如实保留这些缺口；未通过增加实飞、打开sealed test、调整物理参数或控制器增益来制造通过。

详细逐flight结果、负面实验和复现命令见report.md及各实验protocol/completion.json。
