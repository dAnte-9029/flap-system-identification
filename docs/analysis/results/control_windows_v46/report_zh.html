论文定义与本次适配

论文 Figure 2 / IV-C 把线速度与角速度归为一个模块、姿态归为另一个模块。multihead 共享编码器、使用两个解码头；decoupled 使用两套编码器与解码头。

作者公开实现（固定 commit）在训练及评估滚动时补入真实的另一组状态。本次所有分支只交换预测值，输入接口没有未来真实状态，因此是自主滚动的结构适配，不能与论文数值直接比较。

baseline 是 v35：由预测角速度积分姿态。full 改为一个头预测速度导数与姿态增量；multihead 把该头分开；decoupled 再拆分编码器/递归单元，并阻断互补预测状态的跨模块梯度。后两项相对 full 才是结构对照。姿态用三维旋转向量生成单位四元数，所有新组均相同。

参数量 baseline 40070、full 40265、multihead 39977、decoupled 39531（总量差异小于 1.5%）。decoupled 每分支宽度 42，其余编码器宽度 64；multihead 每头宽度 32。未做容量扫描。相同种子并不意味着不同结构的全部初值相同；full/multihead 编码器与递归单元初值逐张量配对 v35。

边界与可复核文件

这次只改变模型结构/对应梯度连接，未改变记录频率、滤波、事件覆盖、训练样本比例或控制器。结果不能单独确定原始传感器噪声，也不能排除数据覆盖问题。decoupled 虽无跨模块参数梯度，仍共享全局梯度裁剪标量及同一训练计划；不是论文独立组件、真值补齐的复现。
