# 针对现有证据缺口的补充激励草案

状态：数据审计后的条件性设计草案，未实现激励、生成飞行任务或授权部署。当前Standard GRU/H26/K50及论文结论不变。

## 1. 先利用已有数据

`nonoverlap_candidates.csv`给出可复查的identity：训练rudder38、common68、differential59、drive169个主要单方向近似孤立片段。先固定同一套工况描述和响应评价，再逐一检查，不按模型误差删选。已有数据能提供相应比较的通道，不仅因单一筛选规则不合格而补飞。

优先确认：同一或相近前飞工况下是否存在正负输入、持续区间、释放后的响应；其他通道如何补偿；初始姿态/角速度、频率、速度、饱和及模式是否可追溯。现有500ms活动规则不能证明后500ms持续恒定，也不能将当前38个片段预先叫作38个阶跃实验。

## 2. 已确认缺口与补证据目标

|优先级|缺口|候选补充设计|要回答的问题|
|---|---|---|---|
|1|rudder验证样本方向与flight覆盖薄弱，同flight双向缺失|原稳定控制器下记录明确外生事件的正/负成对激励，含保持和释放段|方向、幅值、滞后、保持期间与释放后的r响应是否可重复|
|2|common跨日期近似孤立验证薄弱|相同起始工况下的正/负俯仰参考或明确注入点扰动|模型是否能复现实测q响应，闭环补偿是否掩盖输入效应|
|3|roll快速误差受观测带宽影响|先完善同步高频观测；仅在现有差模候选不足时补差模双向段|区分真实快速运动与观测/降采样影响，避免用平滑掩盖差异|
|4|drive已有较多变化证据|优先复用；只有命令→频率或持续区间缺覆盖时再安排|驱动变化是否跨负载一致，不将频率响应当成推力响应|

优先级基于当前证据缺口，不依据测试上某个模型误差来定制损失。新的测试需要新飞行并在采集/开发前划分；Sep8/Sep19已访问，不再作为未见确认集。

## 3. 输入与记录契约先固定

沿用已证明可飞的现有控制器。**参考变化**和**分配后执行器命令扰动**是不同实验：前者验证闭环参考响应，后者才更直接约束命令→机体的合成响应。实施前必须选定一种并记录准确叠加点，不能混用结果。只改变一个设计输入，其余控制器输出仍完整记录，不能宣称它们物理恒定。

每个事件记录独立event_id、计划与实际开始/结束时刻、正负符号、幅值、所选通道及注入点。必须保留最终限幅后四通道命令及实际执行量；没有舵角传感就写明只研究软件命令→机体合成动力学，不能分开识别舵机与气动常数。

同步记录sensor/gyro选中设备、原始或FIFO采样时间、滤波后角速度、姿态sample和publication时间、控制dt/周期号、设定值、限幅前后输出、饱和、PWM、扑翼相位/频率及有效标记。提高logger配置值不等于实际记录率提高；台架核验实际间隔、丢包和滤波链。既有pitch专项日志补丁不是完整三轴同步方案，不能直接当作已部署能力。

软件left/right/differential符号须与现场物理舵面映射核对。当前分析diff=(left-right)/2；旧控制器报告有反向差模约定，不得直接照搬正负解释。

## 4. 时域、工况与幅值

每段至少保留H26历史所需的实际时间，并覆盖起始变化、保持、释放和恢复。0.1/0.2/0.5/1s继续作为预先约定的响应比较时点；若目标是持续保持，试验需在观测上真正覆盖该保持区间，不能从500ms activity指标推断。

采用预先固定的正负平衡顺序，并跨flight反转顺序；保留自然重复差异。初始速度、姿态、角速度、扑频、载荷、电池和风况一起记录。相近工况比较规则在看模型响应前固定，不能选择最有利样本。

幅值、保持时长、恢复时长和事件次数暂不填写可执行数值：需要以现有候选实际范围、物理舵面标定及已批准的任务范围为依据。归一化train q75只是筛选阈值，不是可飞幅值。现有pitch_identification_v1.yaml是旧草案，不能未经确认直接应用于rudder/roll或当前固件。

## 5. 模型比较与决策

每个新事件使用同一实测起点、H26历史、实际最终命令、native dt，对固定三个seed推理；不选最佳seed、不重置保持段中间状态。按完整flight聚合，分别报告方向、幅值、响应过程和原始物理单位误差。原始与预定带宽结果并列，不用滤波后较好分数替代原始误差。

若现有候选已提供重复双向响应，先完成离线对照，可能无需新增该通道激励。若新观测显示命令到实际舵面不一致，先定位该链路；若实测响应可重复而模型不匹配，再讨论模型改动。若实测响应本身跨flight变化很大，先报告适用边界，不靠调tau或控制器让模型通过。

下一项可执行工作是“既有候选响应复核”，本次未自动执行，也未启动补飞、训练或飞控修改。
