# 角动力学单因素实验的诊断依据

已完成离线轴向分解，来源为 oracle 运行保存的 free_run 预测，窗口与
history_lengths 实验一致；未修改数据。运行目录：
`artifacts/september_body_rate_analysis_20260911`，包含源哈希、轴向完整时间曲线
和固定端点。入口：`scripts/analyze_september_body_rates.py`。

此前 oracle 诊断已完成：真实姿态进入旋转和状态反馈时，验证 5 秒位置误差
8.918→5.166 m、速度 4.500→1.765 m/s；真实角速度驱动姿态积分时，姿态
35.24→4.74°、位置 8.918→6.073 m。仅旋转加速度使用真实姿态则 5 秒位置
退化到 9.149 m。它们都是离线干预收益，不是新预测模型成绩。

积分是随体坐标角速度误差的梯形时间积分，仅诊断误差持续性，不是净姿态旋转
或欧拉偏航角。跨日志平均有符号偏差小，不等于单窗口持续偏差小。

x/y 的瞬时误差更大，但 z 的累计增长更突出，并且 train 2s 已有同方向证据。
因此冻结一个最小可检验改动：现有角速度损失的轴权重从 (1,1,1) 改为
(1,1,4)，其他损失和模型不变。不假定瞬时监督一定能消除累计漂移；权重 4
是预先指定的探索值，不是验证网格选出的最优值。

训练采用同起点基线重放，80 epoch、2s objective、26 点历史。基线必须逐位
复现 history_26.pt 才开始候选训练。详细契约见
[body-z weight](../contracts/2026-09-11_september_body_z_weight.md)。后续重点同时看
z 角速度、姿态和实际平动误差，以及短期与其他轴的代价，不以训练损失下降
或 oracle 上限作为成功依据。此文只记录诊断和实验设计，候选结果尚未检查。
