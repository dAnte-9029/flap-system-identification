# 真实数据控制动力学探索

起点：step5 `e64a1ba`；工作分支 `control-dynamics-realdata-v1`。保留工作区既有改动，不覆盖论文结果。

## 数据与实验边界

使用 registry 当前 trajectory_v3_september_expanded 原 train/validation；基线为 StandardGRU64/H26/K50，seed17/23/42。每轮核验 manifest、原始分区产物、准备缓存、checkpoint 和源文件哈希。已知历史工作曾打开独立测试集，不能宣称本项目完全未知测试结果；本轮及后续探索不读取该测试集或其结果，不重新划分日志。归一化、覆盖范围和阈值只由 train 确定。模型未来仅得到候选命令与 dt，未来测量不得进入模型。

## 必须交付的证据

1. 重新执行三seed基线，比较已有预测及各flight指标，验证未来标签污染和未来命令前缀不变性。
2. 在100/200/500/1000ms报告速度、姿态、角速度、逐轴误差和flight差异；明确时间戳含义。训练支持域内的小幅正负命令扰动报告增益、方向、时序和跨seed分歧；这些是模型导数诊断，不是实飞因果标签。
3. 假设、实验对照、数据访问和保留标准先于每轮结果写入独立protocol。先用最小实验区分输入信息不足、模型输入敏感性不稳定及长时累积问题；不凭幅值偏低直接放大舵效。
4. 候选需在原validation的高控制变化组和两日期组不发生主要指标退化，并改善所针对的响应诊断；逐flight和负面结果完整保留。不以单seed或同一模型上的闭环成功晋升。
5. 用现有PX4链路开展受限模型内闭环；固定控制器，对比基线/候选及独立seed模型，检查动作越界、状态越界、模型分歧、异常高增益及终止。检查控制器优化是否依赖单模型误差。集成真实性与实飞有效性分开评价。
6. 交付候选权重与哈希、重现入口和中文结论；用实际证据限定时域、状态/动作范围。不可辨识的持续舵效、物理时延和外部扰动明确列为未知。

## 初始评价规则

预测改善只构成预测门槛；控制门槛还要求支持域、跨模型响应一致性、真实记录条件对照和闭环失效审计。若真实数据无法辨识某通道，不得把它用于已验证的反事实控制；可交付受限候选但必须保留否定结论。100/200ms只是待检验的短时域，500ms/1s为扩展压力测试，不预先承诺任何控制可用性。

每轮更新结果索引；研究交付状态和控制晋升状态分别记录。
