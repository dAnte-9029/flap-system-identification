# 控制导向片段挖掘、非重叠窗口与模型验收协议 v2

日期：2026-09-27。状态：方案，未执行新筛选、重划分或训练。分支`reference-dynamics-data-v1`。

## 1. 目标与现有证据

假设：按输入信息选择或加权数据，可以改善未见操纵响应预测。不能预先认定原模型的问题来自坏数据，也不能将弱响应/预测误差大作为删除理由。

当前全初筛池有57个有效日志、212段、135.68分钟；同配置最终子集有14个日志、66段、36.81分钟。原H26/K50窗口跨度1.52秒、起点步长0.2秒，不能视为独立操纵次数。新方案重新生成非重叠窗口，实际数量必须重算，不能沿用39,304/10,606。

本轮建模边界：**姿态参考端以下的PX4内环＋分配＋执行器＋飞机**。用于小幅参考优化和保留内环的外层预测控制研究。未来输入为roll/pitch参考、thrust_x、manual_yaw以及记录的yaw_sp_move_rate；当前mode与历史状态/参考/执行命令作为上下文。未来执行命令、状态、扑频、相位、空速禁止作为预测输入。恒零yaw_sp_move_rate不具有非零作用的辨识证据。

重要边界：这种模型已经包含内环，不能在模型前再串同一个PX4内环来宣称闭环验证。只有另行训练的“执行命令→飞机”模型，才适用于显式PX4内环驱动模型的重放。首轮A/B/C/D只比较同一参考输入模型，不混用两种输入口径。旧执行命令GRU只是旁证，不是公平主基线。

## 2. 筛选流程

### 2.1 来源和质量

保留原日志，不改旧结果。枚举当前已允许开发的日志，建立raw SHA256、固件、完整参数、输入映射和分配版本记录。sealed/reserved不因合并视图而开放。当前只形成不区分train/validation的描述性池；旧划分仅作为溯源字段保存。

沿用已核验的时间/字段规则作为起点：动态参考/状态/执行命令年龄≤60ms；manual参考≤300ms；模式/landed≤1.2s；零阶过去保持而非双向插值；有效姿态、速度、模式和相位；模式切换、状态估计重置、参数改变、不可修复的时间缺口处断开。任一规则的修改生成新协议，不回改旧结果。

不按响应幅值、方向、跟踪误差、GRU误差或疑似风的单个数值筛选。饱和、弱响应、慢恢复不自动排除。缺失字段按建模任务判断：缺少必要参考阻止该模型训练；仅缺少用于诊断的风估计不等于数据无效。

### 2.2 连续片段与任务标签

保留连续段原始长度；记录Mission/Stabilized、任务目标类型、模式内切换。Mission的position目标不等于几何直线，loiter不等于无价值操纵。巡航范围用实际速度/垂向速度/扑频/姿态等定义，不根据机头俯仰或“跟踪好”判断。

按固件、实际控制路径与参数分组。先以已有同配置组作最小研究，其他组进入待核验池。只在查明差异不改变模型边界下的动力学/输入映射后合并；否则分模型或显式配置条件输入。不能用“参数差异小”直接判等价。

### 2.3 从输入挖掘事件

事件只由参考或执行输入定义：增加/减少、保持、反向、单轴/多轴同时变化、模式内转弯进入/退出的输入变化。事件发现和模型质量评价分开。

第一版输入阈值沿用已有描述阈值：1s内roll/pitch范围≥1°，thrust_x范围≥0.03，manual_yaw范围≥0.03，yaw_sp_move_rate范围≥0.05rad/s。执行命令各通道的事件阈值在训练开发池中按记录量化步长和有效变化分布设定，写入manifest；不能由输出响应设定。尚未确定训练开发边界前，不用全池拟合自适应阈值。

这些阈值只表示发生可记录变化，不是安全幅值、因果可辨识或控制可用门槛。保留变化量、符号、持续时间、命令变化是否实际发生、多轴相关性、同类初始工况覆盖；不要求随后产生可见的正确响应。

相邻输入事件的分析上下文若重叠，合并为一个事件簇，成员事件仍可追溯；不能把频繁打杆切成大量独立试验。单轴证据不足则评估多输入整体响应，不强行给每个舵面因果系数。

每个事件簇保存至少动作前1秒和最后一次输入变化后3秒的诊断上下文，受质量边界截断则标记上下文不完整。不等待输出恢复到预期才选择结束点。该上下文用于事件级完整响应评价，不是把模型训练预测时域改成3秒。

### 2.4 10秒训练块与不重叠窗口

1. 每个原连续片段按时间形成默认10秒管理块。不得跨原模式/质量边界拼接，不足10秒的尾段保留。
2. 10秒块只是管理单元，不是独立试验，也不是强制切断事件的物理边界。跨块的同一事件簇共享`event_cluster_id`和数据划分归属。
3. 单样本H26/K50，最早执行命令历史在t0−0.52s，最后目标在t0＋1s。完整支撑区间长度1.52s。
4. 先按输入事件发生时间、固定规则安放事件覆盖候选，按时间顺序保留互不重叠者；再在剩余空白区以1.6秒起点间隔填充背景候选。规则不得按输出效果排序。事件候选必须包含输入变化在预测区间内；其完整上下文另保留。
5. 用实际时间戳检查任何两个最终样本支撑区间没有交集，不能只检查未来目标是否重叠。A/B/C/D共用这个主样本池，不分别挪动窗口去获得有利相位。
6. 一个10秒块常可容纳6个完整样本；具体由事件安放及剩余长度决定。尾段能容纳1.52秒完整样本就使用，否则仅作为上下文/诊断。不得重复填充、时间拉伸或拼接缺口。
7. 输出采样损失账：原有效时长、块边界/尾部损失、非重叠样本覆盖、事件覆盖不足数、各模式/输入符号/时域的覆盖。

### 2.5 分类和权重

| 类别 | 判定基础 | 处理 |
|---|---|---|
| Q0 明确无效 | 必需字段/时间/语义问题 | 排除相应任务，保留原因 |
| Q1 有输入信息 | 质量有效，输入事件明确 | 控制导向采样重点 |
| Q2 稳态背景 | 质量有效，输入变化少 | 保留基准行为，减少重复采样 |
| Q3 困难/不确定 | 有效但近限幅、记录质量边缘、工况范围外等可追溯标签 | 单列评价，保持训练机会 |

“弱响应”“逆向响应”“原GRU误差大”只能成为事后诊断标签，不能作为降权或剔除条件。D组建议首版相对采样权重Q1:Q2:Q3=3:1:1，先等概率抽flight再按权重抽窗口；三组都要有完整计数。若Q3包含输入事件，仍归Q3，不通过结果标签提升/降低权重。此比例是预注册候选，不是已验证最优值。

## 3. 后续划分：不把整flight作为唯一办法

本次不划分训练/验证。未来执行对照之前必须冻结一个正式划分，否则无法做模型能力验收。

可以做按来源块分组的时间隔离开发评估：同一事件簇、相邻高度相关的块、重复/近重复输入片段不得分两边。跨集合边界最少净空取max(5s,开发池估计的相关时间)，按完整历史＋预测支撑计算；5s是初始下限，不是独立性保证。相关时间仅从开发池评估，不能用评分结果调整净空。

“片段差别大”需用模式、配置、初始状态/输入历史距离和时间依赖报告，不以肉眼或响应好坏决定。若隔离后仍高度相关，合并归属而非继续切细。不同集合的共享flight必须明确列出，这种评估只支持同flight时间外推结论。

为给出跨flight控制用途结论，另需整flight/跨日期外部评价。若本轮只有块级评价，就明确不具备跨flight证据。已有validation已经反复用于开发查看，不能称盲测；sealed/reserved继续保持原边界，不为本研究自动解封或重分配。

## 4. 四组受控训练

| 组 | 主池中的训练策略 | 比较目的 |
|---|---|---|
| A | 全部质量有效非重叠窗口；不按事件加权 | 新输入契约下的完整基线 |
| B | 与C同样数量，按C的配置/模式/flight配额随机取；不匹配事件标签 | 分离数量和训练重复次数效应 |
| C | 目标工况内Q1；不要求输出明显、正向或小误差 | 检验输入信息筛选 |
| D | 保留A数据，按上述分层权重抽样 | 检验不删除困难样本的重加权 |

如果某层无法构建同数量B，报告并收窄四组共同支持范围，不能悄悄让B来自其他日期/配置。所有组同架构、输入/输出、损失、batch size、更新数、学习率计划和随机种子。建议沿用小型GRU64作首个共同架构，3个种子17/23/42；不得同时叠加新相位模块或新物理损失。该网络需要适配参考输入，不是直接加载原执行命令模型就算重训。

归一化统一用A允许的train主池唯一时间行，所有组共享并明确C/B也使用该训练统计；这是为隔离采样策略效应，不声称C训练流程完全没看过其他train统计。内部交叉验证每fold重拟合。validation不得参与归一化、阈值估计或采样权重确定。

先仅做运行成本/有限值的小预检，再在正式训练前冻结更新预算和checkpoint规则。不要用不同数据量各跑同样epoch冒充相同优化预算。报告各样本重复暴露次数；三个seed全量评价，不选最佳seed。旧GRU与局部岭回归/保持预测只作额外参照，A/B/C/D才是数据策略的因果对照。

## 5. 模型能力验收目标

以下数值是本研究建议预注册的研究门槛，不是飞行安全标准；正式训练前冻结，不能看到结果后放宽。任何数量不足或不可测指标标记“不足以评价”，不补成通过。

### G0 数据与因果输入实现

- 所有正式样本完整支撑区间互不重叠，模式/质量边界不跨越；来源、配置、筛选原因、权重、hash完整。
- 分组及时间隔离无冲突；训练统计不读取评价数据；未来状态/执行命令污染不改变预测输入。
- 全部A/B/C/D使用同一评价清单。按flight/来源块聚合，不把重叠窗口或seed当作独立飞行实验。
- 逐轴/符号/工况报告有效事件簇。初步响应结论至少需要各符号10个不重叠事件簇、各覆盖3个flight；不足则限制结论范围，仍可报告预测结果。这是证据数量下限，不是统计功效保证。

### G1 同一真实留出集上的预测能力

- 主指标：操纵事件评价集上0.1/0.2/0.5s目标轴角速度的flight等权RMSE平均，C或D相对A和B均改善至少5%。全部3种子汇报，至少2/3种子同向改善，不能靠选seed。
- 同一完整有效评价集的速度、姿态和各轴角速度平均误差，相对A退化不超过3%；困难层和保持层相对A退化不超过5%。1s另作长时压力评价，不用于补救短时失败。
- 对整体改善按独立flight聚类给出置信区间；若仅有块级划分则在原来源片段层聚类并限定结论。改善点估计过门槛但区间无法排除无改善，只记“有趋势，证据不足”。
- 同时报告coverage、模式/工况分层以及最差flight。不把C只在自己的筛选子集上表现好当总体提升。

### G2 真实操纵响应能力

- 在冻结的完整事件上下文上比较轨迹形状、增量、峰值/持续值、恢复以及p/q/r和速度交叉耦合；不能只比较单个端点符号。
- 输出变化的起始/峰值若不可稳定估计，保留为不可测/弱响应层，报告比例，不按预计方向删除。滞后指标称“该记录口径下的响应时序”，未经执行器独立测量不得称物理舵机时延。
- 可测响应子集中，幅值/增量误差相对A/B均改善至少10%；时序绝对误差中位数目标≤max(40ms,实际相关输入记录间隔的2倍)。manual只有约200ms记录时不能声称40ms精度；需分别报告不同来源的分辨率。
- 强调正负输入和不同保持时间的一致性；这是观察到的闭环参考响应验证，不是裸机因果舵效认证。同构seed导数一致只作辅助，不作为通过条件。
- 如提供经验误差范围，仅在开发池校准，再报告留出集覆盖和宽度；首版90%名义范围的分层经验覆盖建议85%–95%，样本量不足的层只报告区间。覆盖高但范围大于动作收益，仍不足以用于优化。

### G3 限定范围内的控制设计研究资格

参考输入模型通过G1/G2后，可做“外层参考优化器→已含内环的模型”的受限闭环研究。固定参考约束、场景和比较控制器；不得为了通过试验翻转分配符号、放大动作范围或调物理参数。

在预先冻结且共同可比较的场景上，相对参考保持/现有参考策略跟踪代价平均降低至少10%，约束违反率不增加；任何提前终止作为失败报告。采用独立初始化、不同模型族/真实残差驱动的误差情景复核收益，而不只在优化所用单模型上评分。压力情景区分数据支持与假设，不把统计覆盖当反事实保证。

若另外开展显式PX4内环重放，必须使用执行命令输入的飞机模型，并单独重建控制器状态/滤波/调度；同时比较真实状态和执行命令，不能和本轮参考模型指标混用。

G3通过只支持“限定范围内辅助控制设计/参考优化研究”。新控制器实际飞行有效性、广泛RL策略迁移及安全性仍未由模型内实验证明。闭环样本不足、模型间效果反转、收益低于可支持误差范围时，不晋升。

## 方法依据及适用边界

- [NASA：Aircraft System Identification from Multisine Inputs and Frequency Responses](https://ntrs.nasa.gov/citations/20205003364)：支持把幅值和相位随频率的响应作为动力学评价对象；本文阈值并非该文给出的平台通用标准。
- [Wang等：Data-Driven Predictive Control Using Closed-Loop Data](https://arxiv.org/html/2309.05916v1)：讨论反馈导致输入与噪声相关及工具变量条件。其LTI框架不能直接证明本项目非线性闭环数据的因果可辨识，也不说明只做质量筛查就能消除偏差。
