# 受控连续潜状态 Neural ODE 基线

使用 velocity_rate_multistep_v1 真实飞行原八个原生查询、126,237 个训练窗和 44,524 个验证窗，分别来自 121、39 个完整架次。单种子 17。输入用同一 0.5 s 内 6×30 历史和原有 14 维运动谐波摘要，另用截至各时刻实录的四通道 ZOH 命令。模型从零训练，采用两个三角耦合的潜状态组。状态初值与条件向量来自历史编码器。第一组的驱动是命令及条件的非线性神经函数，第二组的驱动还依赖第一组当前状态。各维对角恢复速率在训练中学习，训练结束后固定。联合潜状态通过学习的线性及非线性观测函数，给出相对起点的六维增量。

在每次实际控制跳变处切段，同一常值输入可以合并。在每个速度/角速度查询时刻额外截断该段。第一组稳定线性项及常值驱动的区间解解析；第二组在该区间以第一组的精确中点状态计算非线性驱动，结合指数积分因子进行二阶中点更新。两个状态组串联，第二组不反馈给第一组；这是一种可并行训练的结构化连续潜状态基线，明确区别于对完全稠密任意向量场使用通用自适应求解器。测试一个细分数值参考并扰动查询后的命令，核查真实间隔积分和因果性。此处 Neural ODE 指本地受控模型，不复刻 Chen 等论文基准。

训练使用 AdamW，全窗洗牌，每 epoch 覆盖全部训练窗；每个训练轴用训练标签 RMS 归一化，验证固定使用 39 架次等权的八目标误差。初始学习率 0.001，每连续 5 个验证 epoch 无 0.1% 实质改善减半，最低 0.0000625；最低学习率连续 8 epoch 同样停滞且已至少 32 epoch 才判定平台。比较保留开发损失最小的权重，另存终点。工作预算先留 200 个全 epoch，如成本尚可而仍有改善可继续；遇到实际硬限制，单列未收敛。每 epoch 记录训练/验证、学习率及墙钟。主表统计 0.5/1/2 秒架次等权速度、角速度 RMSE。对应同种子 incumbent 及 TCN 的结果使用相同验证窗。另由统一脚本原样添加已冻结的 H4 增量头，以完全相同的八个目标比较零再训练移植。全部实验都为开发集条件预测。
