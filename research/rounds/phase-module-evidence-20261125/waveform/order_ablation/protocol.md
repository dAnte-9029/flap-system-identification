# H4 第二轮的按谐波阶数消融

前两轮结果已知，这项追加开发集对照在读取新四臂误差前登记。若近期拍形分别含可预测的二阶和三阶分量，固定三阶为真实相位时，二阶改用其真实相位应进一步降低误差；固定二阶为真时亦应看到三阶的额外贡献。若只在一种切换中出现改善，可归因到对应阶数；若错开两者的比较改善而单阶对照没有明确改善，仅保留组合证据。

复用 H4 第二轮全部 121 个训练架次、原八个标签和相同两个原生早期标签、训练集拟合并冻结的条件复矩、三个原主干、相同掩码和无独立起点项的 72 参数读出。每窗用第一轮已有的确定性随机相移 δ（窗标识的 SHA256 前四字节）；错误二阶和三阶分别查询 2(θ+δ) 和 3(θ+δ)，正确阶使用推理时可用的预测 θ，对四臂保持相同条件复矩。每臂独立求解相同岭回归，权重数、历史、解调、命令、预测时域和衰减基完全相同。双真相位臂需要数值复现已存第二轮 conditional 的权重与逐架次均方差，若误差超过 1e−5 单列诊断。

主要检查 39 个开发架次的 0.5、1、2 秒三轴角速度 RMSE，以及事先固定的 0–0.5 秒原生完整目标拍角速度。附同拍二三阶总投影作为频带诊断，各端点速度作为方向性副指标。目标拍的实测相位仅作投影评价。每次比较先按原有规则在每架次内聚合，再对架次等权开方，最后对三个主干种子等权。配对整架次重采样 10,000 次，种子 17，同一个索引同步应用到四臂和三个主干。主要贡献的判据为三个种子收益均为正，且条件比较的描述性 95% 区间不跨零。另列双错臂和两臂的组合对比，不将两阶条件收益视作彼此可加。保持封存测试关闭。
