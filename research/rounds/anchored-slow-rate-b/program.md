# 以历史翼拍为锚点的慢角速度预测

单一开发集对照为固定 seed 17 的 tuned A+C 和冻结其权重、只拟合 B 的 A+B+C。继承 cycle-f4e51b68cd2c10b8 与 study-737f57c053b8 的比较。B 有效的预期是历史锚点到未来拍的角速度向量误差小于持续值，在实际变化最大的四分之一拍上方向优于 A+C，1 s、2 s 角速度端点同步降低，0.5 s 角速度及三项速度保持或改善。竞争解释是只缩小预测变化幅度。复核独立留拍参照、变化大小与方向、首个未来拍作锚点的旧指标。速度输出逐点复用 A+C。单种子开发结果，无封存集。

运行时只用过去半秒之内最近合格的完整拍，Hall 越零须等到越零右侧样本按既有 20 ms 守卫到达，陀螺仪和质量支撑的飞行状态已发布，无跨段、重置和相位质量间断。原生三轴角速度按时间加权。无锚点时全模型回退到 A+C。未来标签用同段完整翼拍拍均值。每个有标签的训练窗均匀抽一个完整拍，seed 17；所有有效原八个端点用于完整轨迹损失。训练标签与独立留拍参考不同源于估计方法，但来自相同测量体系。

B 在绝对坐标中为锚点加线性读出的增量。其特征包括有界的初始编码和锚点响应、A 递推隐状态的因果分段积分、已到达的命令前缀。C 保留已训练一阶绝对波形和二/三阶输出，使用 0.35 s 起点衰减使 t=0 回到实测值。0.35 s 沿用既有一阶读出时间常数。端点和按拍平均的 B 各自对有效三轴项取均值，两项权重相等。一次全训练集 float64 正规方程拟合，按特征二阶矩缩放的 ridge 为 1e-5。正则沿用读出默认数量级，无开发集选参。CPU 或 GPU 等价的有限维凸问题，完成条件为覆盖训练集和方程相对残差小于 1e-8。

评估开发 39 架的原生 0.5、1、2 s 端点，按架次等权。独立评测复用取点与每拍权重。在有锚点的共同窗口报告绝对拍均值误差，等同于从同一历史锚点预测增量的误差，并报告按窗口、按架次等权的向量内积归一化方向一致度。高变化取这一共同支持上参照相对历史锚点变化模长的上四分位，以结果盲态固定分组规则。另复核全支持集旧有相对首个未来完整拍的指标。明确区分全预测拍均值及 B 单独的读出。只运行这一候选。
