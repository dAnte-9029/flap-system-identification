# 满训练预算的配对复验

预注册于首次加长训练前。已有五点短平台在一个模型的学习率仍为 0.002 时触发，另一个模型用了不同数量的更新。本复验沿用原实验的两条假设与四个候选，以强基线为共同参考。主要比较使用相同更新数下的模型，第二组比较考查各模型达到统一充分训练判据后，原来观察到的差异是否仍成立。

| 命令名 | 初始化后从头训练的模型 | 冻结 Git 提交 |
|---|---|---|
| baseline | 逐步查询动力学的强基线 | 8c3a3e585f96e31e893a7287a0006b73daf999f3 |
| history | 保留稳定滤波后的过去运动 | 50e3ae0bedf34b0c85bc07b9ccd18d090c13ee79 |
| current | 同容量编码器，仅保留当前运动 | 149a384c01e2f33b787c87f21f94b0ca51fd7fc6 |
| high | 命令前缀的低阶与高阶时间形状 | 363dfc9ebb99ef2133f2dde65d9cdd797ebd7c00 |
| low | 同容量，仅保留低阶命令特征 | 505a14493a150fec7b61938a9871a80f65ba5452 |

数据与训练均使用强基线提交中的 `experiments/autopilot_flight_dynamics`。使用既有 `velocity_rate_multistep_v1` 准备缓存，训练 121 架次、126,237 窗，开发验证 39 架次、44,524 窗。运行时由原入口校验对应缓存的登记摘要。固定种子 17，批大小 384，按原顺序抽样，计算原损失与梯度裁剪。原 AdamW 使用初始学习率 0.002、权重衰减 0.0001，ReduceLROnPlateau 乘数 0.5、patience 3、绝对门槛 0.001、最低 0.000125。每 512 次更新用完整开发集监测一次原 `dev_mse`。原训练函数只替换末尾的停止判断，所有正式六分项都由同一提交中原样提取的 `runner.py evaluate` 另起进程计算。

1. 在每个模型第 **49,152** 次更新完成时保存当步模型，用 0.5、1、2 秒速度和角速度的六项逐架次 MSE 作严格同更新预算配对比较。原评价对每架次有效窗求三轴平方误差均值，再对 39 架次等权平均后开方给出六项 RMSE。
2. 自第 49,152 次开始检查延长训练停止条件。取最近 **16** 次验证和此前所有验证。最近 16 段训练**实际使用**的学习率都须为 0.000125。用此前最佳 `dev_mse` 减去最近 16 次中的最佳 `dev_mse`；差值不超过 **0.001** 才满足平台条件。当前验证刚触发的降学习率只对下一段生效。记录命中平台的实际步数，使用该步模型做同一套六分项评价。
3. 最多训练 **131,072** 次。到达上限一律标记 `budget_cap` 并评价当步模型，即使最后一次验证碰巧满足条件，也不据此宣称充分平台。第 49,152 步与最终步重合时保留两个评价入口。两套报告都使用当步模型。候选和对照共享相同的架次、原假设预期与配对比较方法。[两条假设与原设计](../program.md)

每一模型的 `runs/<命令名>/source` 从固定 Git 对象导出，`runner.diff` 保存和基线训练函数的逐行差异。`monitor.jsonl` 记录每次完整验证的损失、当段实际学习率和停止判据。`train_info.json` 由原 runner 写入，含全部验证历史、步数、参数量、参数变化等；`stop.json` 标识平台或预算上限。`step49152/` 和 `final/` 分别保存 `model.pt`、六项的 `metrics.json`、与 39 架次对应的 `flight_mse.json`。

从项目根目录运行以下命令。五个模型从独立初始化开始；为给定 GPU 指定一个运行，由调度方在设备空闲时依次启动。运行目录须为新目录。若要重算某一已存档检查点，可使用 `evaluate` 子命令。

```bash
ext=research/rounds/history-identification-20261125/extended
py=/home/zn/anaconda3/envs/flap-train-gpu/bin/python
PYTHONDONTWRITEBYTECODE=1 "$py" "$ext/run_extended.py" check
"$py" "$ext/run_extended.py" run high --gpu 1
"$py" "$ext/run_extended.py" evaluate high step49152 --gpu 1
```
