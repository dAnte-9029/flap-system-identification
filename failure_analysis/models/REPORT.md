# 同一原生整拍上的五模型比较

普通 TCN 已预测一部分慢趋势、基频和二阶角速度。它在前半秒的趋势和基频优于 WingbeatPredictor，后者在二、三阶更准。两者的优劣会随评价时刻改变。

## 支持、模型与投影

复用 66a9ca0 的模型和 periodic-motion-20261125 的 reference.npz。该参考从 39 个开发架次各均匀选择至多 8 窗，要求目标完整拍、连续相位、同段和完整邻拍，在原始两路异步观测上分别查询。速度旋转到决策时刻机体系，角速度保持 FRD。控制使用记录命令前缀。所有模型共同使用 38,276 个查询点，QR 分量比较再统一要求每拍至少 10 点且加权设计条件数小于 100，共同保留 38,276 个点，各时域数量见下表。每个位置以采样时间单元的相对时长加权。拍内积分后依次在窗内、架次内平均，再平均架次 MSE、开方。轴指标见 native_rmse.csv 的 x/y/z，vector 为三轴平方和开方。期段按目标拍时间重心分箱。

| 时域 s | 速度 拍窗数/点数/架次 | 角速度 拍窗数/点数/架次 |
|---|---:|---:|
| 0–0.5 | 180/2496/27 | 193/5195/35 |
| 0.5–1 | 279/3785/27 | 305/7962/36 |
| 1–2 | 460/6097/27 | 499/12741/37 |

以整拍预测减测量的误差为对象，依次对常数与局部线性时间项、一、二、三阶实测相位正余弦做加权 QR。后加入的谐波只计入前序基函数无法解释的部分。数值验证每拍每轴分量能量与残差之和等于总误差能量。joint_* 同时解出全部系数、分别重建各组，组间相关，单独报告。局部线性趋势包含部分非翼拍瞬态和与时间相关的拍内振荡。这里测的是输出误差的投影。目标拍观测只用于评分。

Transformer、按相同八端点续训到平台的 TCN 和 Slow–Fast V2 按历史权重在固定 20 ms 网格及原生命令断点推进，用已有 query 读取区间状态。普通 Transformer 和 TCN 的输入含预测相位一、二阶正余弦，其输出没有显式周期分支。裸主干与 WingbeatPredictor 共享同种子的原主干状态，保持原有八个原生端点的积分前缀，每个额外查询只从前一端点读取局部结果。普通模型和 V2 仅有种子 17，跨架构比较用这个共同种子。

## 使用相位输入的干预、冻结编码的探针

保持权重、历史、控制和预测拍频不变，仅在普通主干每个预测步嵌入之前将一阶未来相位加 π/2，二阶相应加 π。前半秒角速度总误差在 Transformer 从 .7315 升到 .7473，在 TCN 从 .5801 升到 .5846。TCN 一、二阶从 .2557/.2314 升到 .2586/.2353，余下的大部分基频预测能力依然存在。晚期角速度总误差两者均略微下降。该干预表明输出对所给相位特征敏感；历史编码、频率输入等仍能携带时序信息，无法据此量化唯一的周期通路。

用训练的 114 架次、3,091 窗拟合固定岭回归，验证 33 架次、122 窗。每架次均匀选择最多 48 个训练窗、8 个验证窗，取决策后 0.5 秒内第一个满足整拍与邻拍资格的目标拍，再做秩和采样检查。单独在目标拍联合拟合角速度的常数、线性斜率及三对谐波，用作解码目标。比较训练架次均值、展平的完整原始历史和普通冻结网络最后一个历史 token 的表征。特征用训练架次等权统计标准化，固定正则强度 0.1，读出仅看决策前历史。以下为三轴系数 RMSE，谐波对正余弦系数先均方，斜率是归一化拍长上的变化量。

原始历史已包含多数可线性解码信息。TCN 表征可解码三阶，但实际 TCN 的早期三阶误差与持续值相近。当前探针只是线性读出比较，维数随原网络而异。隐状态贡献和目标标签的物理唯一性仍未确定。

速度探针对照使用 90 个训练架次 2,462 窗、26 个开发架次 113 窗。原始历史、TCN、Transformer 的速度局部均值项误差分别为 .3035/.8414/.7627 m/s，原始历史对拍内线性斜率也更准（.2547/.3066/.2877 m/s）。二、三阶的原始历史与 TCN 读出分别为 .0199/.0195 和 .0140/.0138 m/s。隐表征对不同目标保留的信息不同。逐架次详见 probe_velocity_flight_mse.csv。

## 重现

用仓库指定 Python，在本目录顺序运行 ordinary.py、ordinary.py --shift、recurrence.py、score.py、probe.py、probe.py --velocity、figure.py。FLAP_DATA_ROOT 指向含旧研究 worktree、权重、训练及开发缓存的项目主目录，FLAP_POINTS 指向存放逐点推理临时数组的目录。探针的参考生成沿用主项目归档 prepare_reference.py 的历史绝对路径。普通模型与 V2 使用分支 29a57d3 的实现，TCN 加载 66a9ca0 的 external_baselines/best.pt。复用模型不重新训练。probe_flight_mse.csv 为各表征逐架次探针误差。
