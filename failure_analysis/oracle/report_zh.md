# 实验二　仅给二、三阶输运真实相位

在当前 WingbeatPredictor 的二、三阶读出上，未来相位误差显著限制了角速度预测。冻结权重时，把正常输出换为真实相位并取消圆周矩校准，2 s 总角速度 RMSE 降低 0.01826 rad/s。预测相位与真实相位各自重拟合同容量读出后，两者差异扩大至 0.02600 rad/s。速度端点仅显示万分之几 m/s 的差异。

## 冻结与重拟合

在共同的 44,524 个窗口、39 架开发飞行上，先计算逐飞行三轴平方距离均值，对架次等权求 RMSE，再平均种子 17、29、43。括号内为依次列出的 0.5、1、2 s。完整分轴 MSE、每种子的聚合值及配对区间分别见 endpoint.csv、scores.csv、contrasts.csv。

| 高阶干预 | 速度 RMSE（m/s） | 角速度 RMSE（rad/s） |
|---|---|---|
| 无高阶 | .30051 / .49629 / .99655 | .50213 / .51281 / .54617 |
| 冻结，预测相位 + 正常圆周矩 | .30018 / .49616 / .99655 | .48167 / .50332 / .54617 |
| 冻结，预测相位、单位圆周矩 | .30025 / .49626 / .99671 | .48715 / .50444 / .55330 |
| 冻结，Oracle、单位圆周矩 | .30013 / .49596 / .99642 | .47495 / .48718 / .52791 |
| 重拟合，预测相位、单位圆周矩 | .30020 / .49620 / .99657 | .48568 / .50458 / .54649 |
| 重拟合，Oracle、单位圆周矩 | .30017 / .49595 / .99642 | .47353 / .48470 / .52048 |

一阶读出、历史波形和受控主干均沿用原参数。真实相位为目标时刻和决策时刻的原生编码器计数之差，经每架传动比转换为弧度。按时钟拟合协议对重置、失效、40 ms 以上间隙及计数跳变做剔除。非原积分点通过原始网格前缀和一个临时终点单独查询。无高阶和正常两组的六项端点结果均通过与既存 combined/flight_mse.csv 的逐种子逐架次数值核对。

额外重拟合只用 121 架训练数据，每流每轴具有 12 个高阶线性系数。两组共同使用正常八端点及归档方法抽取的两个早期监督时刻、相同有效掩码和对角岭 1e-5。求解目标是现有一阶预测剩余的混合运动。Oracle 仅在诊断中使用。重拟合后的角速度增益在 0.5、1、2 s 分别覆盖 36、39、39 架，三种子同向。以架次配对重采样 5,000 次得到的描述性 95% 区间分别为 [0.00938, 0.01504]、[0.01649, 0.02347]、[0.02244, 0.02982] rad/s。

## 原生整拍与波形

在归档原生整拍上使用独立实测的 38,276 个测点。仅统计高阶空间可解析的整拍（至少 10 点、条件数低于 100）。实测与预测残差先乘原拍时长权重的平方根，再用趋势、一阶、二三阶的有序 QR 子空间计算条件高阶能量。先在窗内平均，再在架次内平均。重拟合后 Oracle 角速度高阶 RMSE 增益早、中、晚分别为 0.03735、0.04986、0.06996 rad/s，分别在 35/35、36/36、37/37 架上改善；同批整拍的原始角速度 RMSE 增益为 0.01045、0.01909、0.03180 rad/s。真实相位的作用集中在它实际驱动的频带。

另取有因果历史高阶估计、且同窗内左右紧邻拍均合格的 1,212 个通道拍，涵盖 159 窗、33 架。分别用决策前历史、目标前一拍、目标前后一拍的平均系数与目标拍比较。后两种可使用决策后的观测。每拍在同一决策相位基准上，按原生权重联合拟合截距、时间斜率及三个谐波；目标拍系数仅作评分目标。以二路系数平方差之和除以二估计均匀相位上的波形差。下表展示晚期（1–2 s）架次和轴等权均值。

| 流与谐波 | 零波形 MSE | 决策前历史 | 目标前一拍 | 前后邻拍 |
|---|---:|---:|---:|---:|
| 速度二阶 | .001266 | .002786 | .000115 | .000080 |
| 速度三阶 | .000310 | .001081 | .000062 | .000045 |
| 角速度二阶 | .036369 | .012970 | .006464 | .005620 |
| 角速度三阶 | .021142 | .010305 | .005214 | .003952 |

速度为 (m/s)²，角速度为 (rad/s)²。角速度历史系数具有跨拍信息，但晚期邻拍的可重构波形明显更接近目标。速度历史系数来自历史各时刻机体系，未来速度在决策时刻机体系表达。速度系数差异会同时反映转动、采样和局部拟合误差。邻拍法也享有距离目标更近、原生采样及相同坐标等条件，此对照无法单独识别幅值变化的物理来源。

在每架至少 6 个该时域样本的轴上，晚期历史与未来的幅值相关系数中位数，角速度二阶/三阶为 .22/.29，速度为 .29/.08。角速度二三阶的系数对相关中位数约 .74/.74；该统计同时包含固定波形方向。晚期角速度历史波形平方误差与命令变化的相关中位数约 .35/.36，与扑频变化约 .26/.18、速度变化量约 .06/.15、姿态变化角约 .19/.25。命令量使用决策至拍中心的一阶指数平均命令与起点之差的范数；运动状态是目标附近的观测量。这里的架次内描述性相关受窗口重叠、工况分布和共同机动影响，不足以证明控制因果效应或输入的独立增益。

## 复现

在本目录使用指定 flap-train-gpu 解释器依次运行 run.py、waveform.py、summarize.py。程序只加载 train/validation 缓存并按本分支继承的预测器及联合原生参考执行，原始飞行文件沿用仓库本地归档。CSV 中 stream=0 为速度，1 为角速度。oracle_gain.png 给出配对区间，readouts_*.npz 保存重拟合权重。开发集已多轮用于研究，结果的范围限于当前读出、现有历史与开发架次。
