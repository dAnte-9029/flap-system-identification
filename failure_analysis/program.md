# 固定诊断范围

从 66a9ca0 的 WingbeatPredictor、速度/角速度注册合同与 periodic-motion 独立翼拍归档开始。只用 train/validation。对照是已有模型输出，不展开网络搜索。观察到的运动条件于实录命令。速度分量比较在起点 FRD，角速度在机体系；信号注入另沿用 vD、q。

|假设|区分该解释的比较|会削弱该解释的观察|
|---|---|---|
|H1 隐式分工|冻结普通模型与相同窗显式读出，分别投影到趋势和相位谐波，保留原积分路径|普通输出在同步分量上不胜持续值，或匹配的周期干预有显著增量|
|H2 标签误分配|真实时刻注入分别已知的非周期脉冲和时变相位同步项，改变窗口和采样密度|在快速机动和变幅时仍同时稳定恢复|
|H3 未来相位或波形难预测|固定主干与一阶；无高阶、正常、无校准、Oracle 无校准；训练集等容量再拟合|供给真实相位后没有改善，且历史系数可以稳定转移到未来|
|H4 分支补偿/竞争|复查相同训练预算下切断慢反馈、移除 B、对慢监督做等范数梯度投影|删除通路重训仍稳定损失，投影不改变端点与拍均的取舍|
|H5 观测与积分|比较原路径额外查询、改变积分节点的同端点输出；分离器对采样率的敏感性|改变路径、标签分布和稀疏化均无影响|
|H6 信息不足|瞬时保持、历史拍均、历史趋势、普通主干、显式 B；区分绝对值和首未来拍之后的变化|因果预测可以在相同飞行上稳定胜历史持续值|

训练决定依据 1–4 及已有充分训练的独立对照。硬分量目标需要能同时保留短促瞬态与变幅波形。对已有梯度干预只在其训练配置及实际种子内归因。精确分组、样本支持、指标与重跑入口保存在各诊断源码及报告。
