# M0 / M1 / M2 的结构与时间合同

本轮预测的是下一步 NED 速度三维与 FRD 角速度三维的**离散残差**，不是七维加速度标签。输出状态为 `[p_N(3),v_N(3),q_wxyz(4),omega_FRD(3)]`，共 13 维。所有模型都调用原 `integrate`：位置梯形积分、平均角速度的 SO(3) 指数更新、四元数单位化。

## 相同输入和递推

- history 为 B×H×20，前 13 列状态、13:17 命令 `[motor,left,right,rudder]`、17:20 为 sinφ/cosφ/frequency；使用原 mask、history_length 和 history_dt。
- 原 V0 状态与相位时间合同；不使用上一轮假设相位传播。原历史位置对起点平移，位置只作积分初值。
- 500 ms 历史编码 GRU(22→64)。历史特征为归一化 v/ω、旋转矩阵六维、带 mask 的相位/频率、两个 mask、dt/0.02，加历史归一化四路命令。
- 未来频率保持末行有效值，未来相位按 `atan2(sin,cos)+2π f elapsed` 外推。相位属于步起点，状态输出属于步终点。缺失相位或频率时未来相位 mask 为零；不用未来真实相位。
- 原生未来 dt 和完整四路命令事件仅来自授权日志；模型连续自主递推，预测函数的八个输入张量没有 target。
- 这是记录未来 dt 和控制条件下的离线预测，不证明在线规划接口或真实反事实效果。

## M0

直接构造原 `VelocityRateGRU(control=True)`，不改实现。GRU16 编码每步规范化控制事件，状态特征 18 维加事件编码 16 维进入递推 GRUCell(34→64)，Linear(64→6) 生成归一化残差。37590 参数。

## M1：分离当前步控制通路

移除 event_gru，并令递推 GRUCell 输入只有 18 维状态／相位／dt 特征：

`z_k = GRUCell(features(s_k,phase_k,dt_k), z_(k-1))`

`delta_vw_k = output_scale * [F(z_k) + B(z_k) Ψ_k]`

`F=Linear(64→6)`；`B=reshape(Linear(64→48),6×8)`。B 的状态相关性通过 z_k 获得。当前步事件不能进入基础递推或 B；过去控制的影响可以经历史隐藏态和已经预测的状态传入。这里 z、F、B 不是唯一可辨识的物理分解。

命令参考 `u_ref` 固定为该 receiver 历史最后有效行的四路命令，整个未来时域保持；不是未来均值，不从 donor 起点提取。命令变换：

`T(u) = [motor,(left+right)/2,(right-left)/2,rudder]`

先计算原命令差再做线性变换。用原训练命令尺度构造 S：motor/rudder 沿用原尺度，common/differential 共用 `sqrt(scale_L²+scale_R²)/2`。没有拟合新归一化或假设四路独立激励。令 `δ_j=S⁻¹ T(u_j-u_ref)`。

每步时长 h，事件覆盖半开区间 [a_j,b_j)，τ_j=b_j−a_j；定义两个精确 ZOH 时间矩，拼成八维：

`Ψ0 = Σ τ_j δ_j / 0.02`

`Ψ1 = Σ τ_j ((a_j+b_j)/h−1) δ_j / 0.02`

第二式是区间内线性时间权重 `2t/h−1` 的精确积分。第一矩区分整体偏离；第二矩区分相同平均命令的早／晚变化。事件先经过原 `exact_zoh_merge_us_v1`，整数微秒验证、去零、合并同值；不拉伸时间。h=0 的 padding 得零矩。命令处处等于参考时显式项严格为零；冗余分段不改变结果。

所有真实事件及持续时间都参与计算，但**两个矩不是任意复杂波形的一一编码**：不同高阶波形可能投影到相同矩。这是本轮主动选择的低复杂度表示限制，应作为架构差异记录；不能声称完整保留了 GRU16 的编码容量。零偏离约束也不代表基础动力学在恒命令下为零。

Ψ 是无量纲归一化命令偏离乘以时长／20 ms；B 是学习系数；最终 output_scale 将六维残差恢复为 m/s 和 rad/s。没有将 B 当真实加速度、力矩或物理控制效能。F 沿用离散残差定义并读取 dt，不额外改成加速度积分。M1 共 36534 参数，比 M0 少 2.81%。

## M2：显式一阶相位调制

`B = B0(z_k) + phase_valid * [sinφ_k Bs(z_k) + cosφ_k Bc(z_k)]`

同一 Linear(64→144) 生成三个 6×8 矩阵，其余完全同 M1。M1 的 z 已隐含历史和递推相位，M2 增加的是**显式调制通路**，不是从“无相位”变成“有相位”。系数本身依赖 z，因此不能把它视为严格带限的物理谐波模型。42774 参数，比 M0 多 13.79%。

log-local 相位零点未跨航次统一，源码未证明真实采样延迟。M2 系数不解释为真实翼拍相位气动力，不使用真实未来相位补偿。

## 初始化、训练和约束

F 头按原实现零初始化；B 头权重为零均值 std=0.001 的小随机数、偏置为零。Ψ 为确定性非训练投影，B 不以两个同时为零的可训练因子相乘；首批可获得非零控制梯度。没有固定差动→p 的符号，没有 B 增幅奖励或 C/H 目标。

三模型同种子、相同原归一化和损失；不同结构的参数抽样顺序不同，不能声称逐权重相同初始化。独立 CPU 生成器固定每轮 batch 顺序，三个模型的顺序 SHA256 完全相同。全部从头训练，smoke 权重丢弃。
