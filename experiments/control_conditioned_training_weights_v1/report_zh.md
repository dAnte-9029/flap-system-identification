# 面向控制响应的训练权重：设计与离线审计

结论：**推荐 W1 进入另行授权的小规模试训练，W2 保留为备选。** 两者均通过预先固定的数值集中度审计，增强覆盖多个航次、正负方向和控制配置。W1 更简单，W2 在本数据中增加了较晚时刻的相对贡献。本轮没有模型性能证据，不能声称方向或幅度改善。

实际训练 **0 次**，优化更新 **0 次**，未使用 GPU。只读历史 `velocity_rate_multistep_v1/main_50hz` 的 train；未打开 validation/test Parquet、测试日志或预测标签，未读取模型 checkpoint。基准为 `4fa56ea3893be814d226d1bfd3ad1ef966a15d67`，新分支 `exp/control-conditioned-training-weights-v1`。此前闭环信息量结论仅用于限定解释，没有使用已有留出误差来选择权重。

## 数据身份、资格与时间合同

复用原 H1000 缓存中的 `dt/future_mask`、注册 `train_windows.parquet`、历史数据清单与原生 actuator motor/servo 命令。107,920 个窗口、94 个航次/原日志，500 ms 历史、1000 ms 名义训练时域。六个窗口有 51 个未来步，其余有 50 步，全部保留。读取 samples 的过去状态字段用于资格判定，**没有读取 `target_*` 列或 NPZ 的 `target` 成员**；原生输出时间戳及支持掩码不属于运动标签值。

H1000 与注册 H500 按 `flight_id + origin_sample` 一对一关联，并逐一核对 `start_sample / segment_id / initial_measurement_us / decision_us`。107,920 个身份全部匹配；其中 96,095 个也存在于旧 scope 候选表。对全部 H1000 起点重算冻结的过去信息规则，已有候选的 AUTO_stable 标记 **零差异**。55,091 个满足 AUTO_stable；未出现在旧候选表的起点中没有额外的 AUTO_stable 窗口。没有使用最近邻时间拼接、行号猜测或新的匹配筛选。

资格沿用 26 点历史网格、完整过去频率/状态有效且无 failsafe/模式变化、AUTO_MISSION=3、速度模 4–12 m/s、机体系前向速度至少 3 m/s、频率 2.5–5.5 Hz、滚转/俯仰绝对值不超过 25°、角速度 RMS/起点模不超过 1.2 rad/s、垂向速度绝对值不超过 2 m/s、历史命令近限幅比例不超过 5%。这里“速度”沿用旧 scope 的 **三维 NED 速度模**，没有改成水平速度。没有按未来 high_dynamics、响应符号或预测误差筛选。

## 三种目标与接口

设 `e_ik` 是原位置、NED 速度、SO(3) 姿态测地角、FRD 角速度四项误差，`loss_ik=sum((e_ik/loss_scales)^2 * component_weights)`。不改变四项相对权重、尺度、标签或积分器。

- **W0**：每窗口有效未来步平均，再窗口平均，直接调用原 `window_loss`。
- **W1**：原生 ZOH 精确求 `delta_d=mean(d)-d0`，`w_i=1+clip((|delta_d|−0.02)/0.08,0,1)`。仅 AUTO_stable 且支持完整时增强；标量 Loss 为 `sum(w_i L0_i)/sum(w_i)`。整段 1000 ms 都受影响，即使控制资格来自前 300 ms。
- **W2**：每步累计最近 300 ms 内 `|d−d0|>=0.05` 的时长，`w_ik=1+clip(exposure/100 ms,0,1)`；窗口内按有效加权步归一化，随后窗口等权。它保留窗口总份额，但重新分配时间关注。

W1/W2 独立，不叠加。所有不符合资格的窗口保留原权重 1。W2 支持检查逐步进行，后面控制无效不会追溯改变早先**原始步权重**；窗口内归一化分母按用户指定公式包含所有有效步权重，因此早期步的最终归一化系数可依赖整窗权重总量。这属于离线 Loss 分配，不能称为在线因果估计，也不进入模型输入。

`weighted_loss.py` 提供统一 scalar 接口及 per-window 接口，接受调用方原 train-only `loss_scales` 和四项权重。权重 detach，不参与求导。padding 不参与分子/分母，padding 中 NaN/Inf 也不会传播。全 1 权重直接走原函数，数值与梯度严格相等。W1 按 **当前 batch** 自归一化；本文全数据份额和 ESS 是离线总体描述，不声称与随机小批量梯度期望完全等价。

## 全局与三折结果

ESS=`(sum w)^2/sum(w^2)`，只表示数值集中程度，不是独立飞行实验数。窗口高度重叠；不同折拟合集也重叠，数量不可相加为新样本。

## 航次、符号、配置与耦合

W1 正/负增强分别为 **18,438 / 17,764** 窗口，分别覆盖 **93 / 93** 航次；新增权重最大单航次占 **1.82%**，前五占 **8.32%**。增强覆盖 15 日期、13 个已知固件、29 个控制参数哈希；最大单配置占新增 W1 权重 14.50%。未知固件那一航次仍保留统一权重。控制配置来自旧日志头审计，**仅代表初始参数哈希，未保证航中参数绝不改变**。

W2 正/负阈值暴露也分别覆盖 93 航次，滚动暴露总量中正向占 49.69%；同一窗口可能同时包含正负暴露，不能相加当独立事件。W2 原始新增步权重最大单航次占 1.64%，最大单配置占 13.55%；归一化后航次总份额仍完全不变。三折正负覆盖各为 75/75、82/82、76/76 航次；最大单配置新增 W1 份额为 18.13%、13.56%、15.20%，没有由单一符号或配置主导。

AUTO_stable 总窗口贡献由 W0 的 **51.05%** 增至 W1 的 **56.74%**，W2 保持 51.05%。按历史速度模，4–6 / 6–8 / 8–12 m/s 的全训练份额从 19.04 / 49.12 / 30.98% 变为 19.22 / 49.12 / 30.90%，没有明显转移到高速区。

按前 300 ms 差动平均偏离绝对值，0–0.02 / 0.02–0.05 / 0.05–0.10 / ≥0.10 的份额从 32.26 / 35.02 / 23.37 / 9.35% 变为 28.50 / 33.80 / 26.79 / 10.91%。按前 300 ms 内超过 0.05 的**累计**时长，<100 / 100–250 / ≥250 ms 的份额从 48.41 / 43.63 / 7.96% 变为 43.85 / 46.71 / 9.44%。这不是连续驻留时长，也不是执行器实际运动持续时间。区间使用左闭右开，完整记录见 coverage CSV。

完整四路控制仍耦合，命令不等于实际舵角或气动力。前 300 ms 有符号平均变化的 differential–rudder 相关从 −0.118 变为 W1 加权 −0.166；differential–common 从 0.093 变为 0.097。低线性相关不能证明独立激励。W1 不保证纯差动激励，不能把较大权重解释为较可信的物理效能监督。其他状态均值对照在 `state_distribution.csv`，资格已限定所有增强窗口的历史动态上界。

## 隔离与验证

直接复用冻结 holdout 协议、索引和 pair assignments，每折独立遍历其拟合窗口生成完整数组，与全训练逐窗口确定性结果一致。无统计拟合步骤，阈值来自预先配置；不从全训练估计任何折内阈值或尺度。每折核对 flight 和原日志 SHA/boot 与 held/validation 无交集。未改变 48 主对、11 依赖分量或背景规则。

自动测试 **18 passed**：原 W0/全 1 的损失与梯度在 float32/float64 下严格等价；独立四项误差和加权归一化；padding；零控制、正负对称、坐标符号；ZOH 冗余分段；阈值与新鲜度边界；更晚事件被污染不影响先前 W2 原始权重；无效支持；权重 detach；真实数组和三折身份隔离。

独立实现从原 motor/servo 表重新查找事件，以区间交集长度而非主实现积分函数复算 **4,458 个窗口，覆盖全部 94 航次**，差动积分及 W1/W2 最大差异均为 0。全量与三折所有数组的窗口身份、时间单调、padding、份额及 ESS 独立复核；ESS 最大差异 1.46e−11。历史源发布可用性检查覆盖全部窗口。原生积分是抽查而非全量双实现，范围明确保留。复核开发时曾发现原始 float32 命令直接相减与主实现 float64 运算产生约 3.4e−9 差别，统一**运算精度**后相等；没有改变原始命令、阈值或权重定义。

## Q1–Q5 与下一阶段

1. **Q1：覆盖多个航次吗？** 是，正负增强各覆盖 93/94 航次，并跨日期、固件和配置；重叠窗口仍不是独立证据。
2. **Q2：改变什么？** W1 改变窗口间份额，整窗时间平均不变；W2 保持窗口间等权，改变每窗口内时间分配。均保持原四项轨迹监督。
3. **Q3：集中严重吗？** 固定工程门槛均通过；W2 有温和的晚期倾向，需在下一轮明确监控。ESS 不认证可辨识性。
4. **Q4：三折稳定吗？** 三折 W1 ESS 比为 95.09–95.16%，最高航次份额增幅 1.091 倍，正负及多配置覆盖保留；规则不需要留出统计量。
5. **Q5：推荐哪个？** 选 W1，原因仅为训练侧覆盖稳定、时间含义清楚且实现更简单，W2 备选。没有依据声称 W1 能纠正特定旧失败病例。

已冻结 `next_stage_protocol.json`：原三折 × M0/M1 × W0/W1 × seed17，**计划 12 次、每次 6 epoch，从头训练，本轮执行 0 次**。同折重算或哈希核验仅拟合航次 normalization/loss_scales；同窗口、batch 顺序、更新数、优化器及统一 6 轮 cosine。best 仅依据原 27 validation 航次等权的 **W0 原四项**轨迹损失，不依据加权验证 Loss 或留出响应。评价固定 300 ms B/D（270 ms 平均），方向门限 0.1、敏感性 0.05/0.2，保留正负幅度偏差、增益、方向得失、p/q/r、事实误差及依赖分量。三折已经多次暴露，不是全新独立盲测；C 增大不是成功标准。

本轮到此停止，不训练、不推理比较、不搜索新 Loss。权重是轨迹目标的关注分配，既不是因果权重、倾向评分，也不是对真实反事实响应的监督。
