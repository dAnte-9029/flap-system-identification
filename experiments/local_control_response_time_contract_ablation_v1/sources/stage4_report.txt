固定提交 · 8 条训练日志 · 无模型训练或新实飞
本轮已把“闭环机制资料可取得”推进到实际窗口内核验：下载并校验 8 条允许的训练 ULog，读取对应精确固件源码，执行预先锁定的时序、模式和内部计算一致性检查。另完成完整开发 Parquet 与原匹配全候选产物的恢复检索。
核心结果  在合计 1177.538603 s（约 19.63 分钟）的固定训练窗口中，57,245/58,873 个 torque 记录满足严格跨消息匹配，指定的 10 类代数检查均无超出预设容差的违例。每条窗口均经历 STAB→AUTO_MISSION→STAB；不能将整段数据视作同一个固定线性反馈律。
新增证据确认了所审窗口内控制命令的来源、阶段和若干软件计算关系。它未验证学习模型在换用其他控制序列后对真实运动的预测；也未生成离线策略价值或 MPC 闭环性能保证。
本轮没有模型训练、重新推理、仓库修改、控制器实现或封存测试轨迹访问。阶段三的规范化响应重放结果保持原有证据地位；本轮没有将机制恒等式当作新的运动误差指标。

固件源码审查包括角速度/姿态控制、模式管理、横纵向控制、SLOW 积分转移、gain compression、控制分配、输出路径及日志配置。75 个文件的 Git blob SHA 均与固定树一致；另与此前保存的 7 个源码快照 SHA256 全部一致。日志版本和字段一致仍不是实飞二进制、编译选项或全部未提交改动的认证。该仓库自身的 isolation audit 记载了提交前 dirty build，其 binary hash 不能代替实飞 binary hash。[S1]

二 模式、参考与控制命令的实际来源
58,877 个网格点中，AUTO_MISSION（3）占 33,677 点、57.199%；STAB（15）占 25,200 点、42.801%。按同一保持规则，姿态环、角速度环和 allocation enabled 均为 1；armed 为真、landed/failsafe/VTOL/transition 均为假。模式/控制标志最大发布年龄约 0.5 s，landed 约 1 s；保持值并非每格新测量。[D1]
图 1  固定训练窗口中的模式时间线。每行从各自保留窗口起点计时；A/B/C 是配置组。轨迹与阈值未据该图重新选择。
STAB 的 flags 使外环进入 OTHER，不执行 AUTO 外环参考发布；手动姿态分支和角速度内环仍工作。于是外环参考在整个窗口看起来只有约 51.7%–61.3% 的 50 ms 新鲜消息覆盖，但限定到 AUTO 网格后达到 99.974%–100%。该解释有固定源码分支与模式分层统计共同支持；没有删除切换边界或重选窗口。[S2、D1]
同一版本的字段名称订正
主诊断保留了旧名称 npfg_status 和 airspeed_validated.selected_airspeed_index 的缺失记录。精确消息定义随后确认本版本名称为 fixed_wing_lateral_guidance_status 和 airspeed_validated.airspeed_source。补充审查明确标为“主结果之后的 schema 订正”，原冻结结果、窗口和阈值均未改写。[D2、S3]
正确 airspeed_source 在全部保持网格中为 1，对应 sensor 1。guidance status 在 AUTO 与 STAB 下的 50 ms 消息覆盖都为 100%；但 mode manager 在相应 local_pos/固定翼分支下可持续给既有 guidance 内部状态加新发布时间，发布并不受 AUTO 外环 active 条件限制。因此，新鲜消息不能证明 NPFG 本周期重新更新，更不能证明内部状态就是外生参考。[D2、S2]
三 时序、采样和可观察性
基础协议在读取新增窗口时序前锁定；外环主题补充 amendment 01 同样在首次解析前保存。网格间隔 20,000 μs；仅使用过去已发布消息，不用未来插值。所有动态消息并列报告 25、50、100、200 ms 年龄阈值，不选结果最好的阈值。标志另报告保持值与年龄，不能将低发布频率直接解释为控制循环频率。[D1]
各格为 8 航次的范围，表示消息发布时间新鲜度，未合并为“传感器真实有效率”。finite 字段检查另存；尤其 motor 的 NaN 在本固件中可映射 disarmed，不能不查分支就当丢包。模式、landed、任务航点等可能按变化或低频发布，任务航点保持很久不等于缺少参考。[D1、S3]
SDLOG_PROFILE=4097 对应 default 与 flapping profile。源码中部分参考、控制项和命令记录间隔为 20 ms，angular_velocity/output 为 10 ms；adaptive 50 ms、gain compression 100 ms、allocator/manual 200 ms。实际统计与这些量级相符；若存在 logger_topics.txt 可替代配置，因此报告仍以原始记录为准。[S4]
所有已审原生主题的时间戳未发现逆序或重复步。58,873 条 torque 与 terms 有 58,544 个唯一正采样戳可配对，进一步要求 status 有序发布后剩 57,245 个。匹配周期中 status 到 torque 的发布差为 0.003–0.039 ms；这是软件发布顺序差，不是舵机机械延迟、驱动总延迟或真实气动响应延迟。[D1]
四 源码定义的内部计算检查
terms 与 torque 必须具有相同且唯一的正 timestamp_sample；status 本身没有该采样戳，以 terms.timestamp ≤ status.timestamp ≤ torque.timestamp 且后两者间隔 ≤2 ms 配对。2 ms 是预先固定的审查条件，不是源码定时保证。未匹配的 1,628 条不纳入对应跨消息结论，也未按偏移搜索重新配对。[D1]
所有等式统一用 |lhs−rhs| ≤ 10⁻⁵ + 10⁻⁵|rhs| 判断浮点一致性。该容差不具有物理单位的控制准确性含义。主检查只解释原已规定的内部关系。
每类关系在 8 个航次分别记录，共 80 个汇总行；总标量核对数为 534,258，均有限，全部满足固定容差。这些关系共享内部变量并存在时序依赖，不能把行数或标量数当作独立实验次数。独立复核者直接从保存的窗口 NPZ 重建匹配和公式，未运行原脚本，80 行数量、最大残差和违例数均一致。[D3]
计算阶段必须对齐
SLOW 的积分转移发生在本周期 PID/FF 输出计算之前；rate_ctrl_terms.i_term 记录转移后、自然积分更新前的 I，而 rate_ctrl_status.rollspeed_integ 是自然更新后的 I。用于本周期输出的 gain compression 是更新前的值；另一 gain_compression 消息可含更新后的值。将这些字段不分阶段直接相减，会制造伪误差。[S1]
roll 重构要求非 VTOL/非 tailsitter、rates enabled、静态与动态 roll trim 为零且各轴控制输出有限。8 窗口记录满足相应参数/标志，terms 三轴 output 无非有限记录、reset_this_cycle 均为 0。源码在 |transferred| ≤ FLT_EPSILON 时忽略该项；事后分支核对发现 1,981 条非零微小值，最大被忽略的 |g×transferred| 为 8.86×10⁻⁸，低于既定容差。没有据此改动主公式、容差或结果。[D1、S1]
局部覆盖限制  adaptive 与 status 的严格同发布时间匹配合计 9,279 个，但 log_9 只有 5 个，其余航次为 988–1,655 个。零残差只能约束已匹配值，不能据此说全段 adaptive 动态已验证。
五 控制配置与物理作用之间的边界
在已知矩阵、无附加项/故障且未 clip 的理想软件分配条件下，可写 u_left≈0.5τ_pitch−τ_roll/1.1，u_right≈0.5τ_pitch+τ_roll/1.1，u_rudder≈τ_yaw，motor≈thrust_x。此式来自源码和配置，本轮没有将它拟合为实飞物理效能矩阵。PWM MAIN 的命令映射与通道反向也不提供舵面位置反馈。[S5]
原生分配器状态与限幅标志均已保留，不能把“命令可重构”扩展成“真实作用力可重构”。整个机制审查的比较对象都是同一软件链中的量，而不是更换控制后的独立运动后继。
六 文献条件现在能推进到哪一步
本轮延续已完成的全文筛选，不重复列出全部 28 项文献。以下是此次实证核查改变的准入判断，原文定位保存在 diagnostic_protocol_suggestions.json。[L26、L15、L2、L18]
Colin 等的定理研究含真系统的指定 LTI 预测误差模型，稳定对象、对角且稳定/逆稳定 monic 噪声滤波、稳定闭环的有理 K，以及所用结果要求的外部激励独立性。其结构矩阵满行秩一般仅是充分条件。本轮没有拿原始输入协方差、GRU 雅可比或模式变化来替代该矩阵，也没有因未获证书就宣称一切控制作用都不可辨识。[L26，PDF pp.2–4、6–7]
Forssell–Ljung 区分直接法的噪声结构与间接法的控制器知识要求；外部参考的名字、变化和时间领先均不足以证明它与创新独立。知道固件可缩小机制不确定性，但仍需将噪声、反馈生成和候选对象结构与具体定理一一对应。[L15，Paper A，PDF pp.103–108、137]
SUMO 迁移应限定为可检验的诊断
SUMO 实际使用第 k 近邻的欧氏距离，经 log(1+d_k) 变换；库向量为真实转移 (s,a,s′)，主要查询包含模型预测后继。它不是 k 个距离的均值。原论文用独立 MuJoCo 环境重放合成 (s,a)，得到真实后继后评价评分与误差的相关性；当前实飞日志没有这种未执行动作的 oracle。[L18，PDF pp.3–4、6–7]
以后若恢复完整库，可先审查评分与实际已执行动作下的预测误差是否相关。跨航次排除、仅训练数据定标和固定历史/控制表示是本项目需另行冻结的设计，不是原论文直接提供的定理。即使事实误差相关性成立，也不证明 kNN 分数是所有候选动作的真实误差上界。附录性能论证使用 admissible estimator 等附加条件，不能由拼接后距离不减自动得到。[L18，PDF p.11]
上述参考材料及 30 份已获取全文仍在原 Google Drive 文献目录，本轮没有制造新的“待手工下载全文”缺口；当前最直接的外部依赖已转为注册开发数据。

不能推出
A：EN=0；B：EN=1/CMP=1；C：EN=1/CMP=0。
A 关闭 SLOW；B 为 paired LPF comparator，绕过特定持续性/反向门控；C 为原 SLOW 路径。
三组随机分配、环境一致，或三组给出同状态控制反事实。
I 与转移状态 S 使用 accepted-delta 配对。
某些转移阶段 ΔI+ΔS=0 是控制实现的设计关系。
该关系等价于新的独立控制激励，或证明真实运动对输入的导数。
flap_slow_roll_baseline 在本周期转移后计算。
它是不再额外加 S 的软件中间量。
它是关闭 SLOW 时真实会产生的控制或运动反事实。
effective_slow_tail = effective_slow_torque/1.1。
这是软件控制分配坐标的换算。
它是测得的真实舵角，或可据此得到气动增益。
