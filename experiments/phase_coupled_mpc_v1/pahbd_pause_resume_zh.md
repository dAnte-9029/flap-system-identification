# PA-HBD 安全暂停、恢复及双卡策略

当前 A17-20261103-1115 已按用户指令停止。最后日志1827步；已验证可读的完整 checkpoint 为1824步，恢复需重跑3步。原输出、失败信号证据及停止说明保留。没有恢复正式训练。

## 实现

- 每200次完整 optimizer 更新保存 recovery checkpoint；不增加验证，不改变采样或 Adam 更新。可用 `--recovery-interval` 调整保存频率。
- 写临时文件、fsync、硬链接无覆盖发布，再写 latest.json 指针。失败写入不发布残缺 checkpoint；旧 checkpoint 不删除。
- 训练输出目录的 PAUSE_REQUEST 文件，或初始化后的 SIGTERM/SIGINT，请求安全暂停。完成当前更新后保存 pause checkpoint；验证中请求则完成当前验证再保存。暂停不是立即退出，不能追加 SIGKILL。
- 保存模型、Adam、采样器（含抽样顺序/RNG）、Torch CPU/CUDA RNG、累计步骤、best 与待验证状态。恢复点恰在验证边界时先验证，再开始下一次更新。
- train 子进程以75标记暂停，队列写 PAUSED.json 并停止，不启动下一任务；失败与成功仍分别记录。
- `run_pahbd.py --checkpoint` 在新输出目录续训；`--steps` 是原总预算而非额外步数。配置、manifest身份、相位合同、验证成员、采样索引和验证间隔须匹配。best 可引用旧目录，须保留原结果。
- 修复旧加载器把 CUDA RNG 字节状态搬到 GPU 导致无法恢复的问题：checkpoint 先读入CPU，模型及Adam状态再按设备恢复。
- `scripts/control_pahbd_runs.py pause --run-root ...` 请求暂停；`prepare-resume --run-root ... --checkpoint ... --output ...` 只生成单任务恢复队列，不启动。新队列引用当前代码SHA，启动器仍拒绝脏代码或SHA变化。现有未修改的旧训练程序不支持该暂停协议。
- 本实现只支持同一可见GPU布局的严格恢复；调换可见设备、跨硬件/版本不宣称位级等价。断电/SIGKILL只可回到最近已成功发布的恢复点，不能保存未完成更新。

## 双卡优先策略

1. 六个独立实验采用两个单卡worker，各绑定一张GPU和不同物理CPU性能核（避免使用同一核心的两个超线程）。每worker顺序执行三个任务，例如 GPU0: A17/A29/A43，GPU1: B17/B29/B43。独立日志、RNG、checkpoint，不合并梯度。A17恢复时仍遵守其原随机序列；不能重抽窗口。
2. 先以相同真实窗口测量单任务与双任务并发的总 steps/s、各卡耗时、CPU核及存储竞争。理论接近两倍总吞吐只是上限，不是已经实测的收益。
3. 只有一个任务时，可以探索第二张卡分担固定 checkpoint 的验证，按原窗口顺序归约。必须等待完整验证结果才能可靠确定best/完成状态，并处理快照传输、失败及暂停语义；本轮不实现。验证有多大耗时占比，决定这一方案的收益上限。
4. 不优先采用DDP或模型切分：网络很小、积分串行依赖强；DDP合并多个窗口会改变逐窗口Adam更新，模型切分又增加通信，不能仅因GPU空闲就推断加速。

## 普遍提速策略

- 优先消除串行积分核心的Python调度和小kernel开销；上一轮协方差解析化、控制事件缓存及loss批量化已完成，避免重复做同一优化。继续融合核心前必须对真实四时域的预测、loss、梯度和ZOH事件作对照。
- 编译路线曾受Triton环境错误阻断。应在独立环境解决并测量图中断/重编译及稳定吞吐；不要修改现有训练环境或把首次编译时间当稳定成本。
- CPU预取与不可变事件缓存保持抽样顺序，预取线程不能推进已提交采样器状态；暂停保存的是已完成更新位置。只在测出加载/调度占比后实施，避免预取GPU图或重复显存占用。
- 不用更大batch、梯度累积、float32、扩大积分步长冒充等价提速，它们会改变更新过程或数值合同。
- 衡量总训练/验证墙钟时间和完成步数，而不是单纯追求GPU利用率。恢复快照增加少量I/O；应另外测其占比，再调整保存间隔。

## 验证边界

15项针对性测试通过（另7项不相关测试未选取）。测试覆盖CPU及GPU连续训练与中途恢复的参数/Adam逐位一致、窗口顺序、验证边界、最终步待验证恢复、保存失败不发布及禁止覆盖、队列成功/暂停/失败退出。使用短合成窗口验证调度语义，不作为真实窗口吞吐或长期数值一致性的证据。已有1824步真实checkpoint进行了只读加载验证；本轮无真实数据训练或封存test访问。
