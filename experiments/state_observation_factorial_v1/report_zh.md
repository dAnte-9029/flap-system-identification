# 初始状态与未来角速度标签的2×2积分消融

## 结论

主要改善来自未来角速度标签B，而非两点因果初值C1。保留C0、只替换未来标签的T01，已取得接近T11的姿态积分一致性。建议保留C0，把B列为下一轮小规模监督目标候选；不再推进C1短时外推。当前证据支持准备并开展一次受控的6epoch训练比较，但不能预先声称它改善GRU控制响应。

本轮训练0次、模型推理0次。只做确定性运动学积分，不修改网络、Loss、原数据或旧成果，不读取test。

## 范围与方法

基准为 `d111ff23bee90464f5946f7143eb94528da0d922`。历史数据版本 `velocity_rate_multistep_v1/main_50hz`；train 107,920窗口/94航次，validation 36,332窗口/27航次。未重做匹配、Oracle或原始日志审计。

T00=C0+A，T01=C0+B，T10=C1+A，T11=C1+B。完整复用上一轮T00/T11结果、C0/C1初值、逐行B和连续支持长度，仅新增T01/T10全量积分。上一轮历史表未包含全部未来末端B节点：854,973个唯一节点直接复用，15,808个缺失末端节点通过已有train/validation原生Parquet和原插值规则恢复，没有扩大支持或重新估计C1。来源记录见 `results/run_receipt.json`。

四组保持原初始位置、速度、姿态、未来速度和dt；使用原 `velocity_rate_gru.integrate`。四元数按当前与下一步角速度的梯形平均积分，未来记录姿态仅供计算误差，绝不重置积分状态。所有组采用相同连续有效前缀，缺口后不恢复、不外推。完整H1000子集另报，不将不同支持样本的数字直接解释为方法变化。

每窗口先对有效步SO(3)测地角平方取均值，随后窗口等权平均、开方；终点为各窗口共同支持末端。CSV另外提供航次等权统计。窗口存在重叠，本分析不构造独立实验数量或显著性区间。B是原生角速度的离线时间参考，不是无滤波延迟的绝对物理真值。

## 单因素与交互

以下是每窗口路径MSE差的平均值，单位度²；负数表示积分误差减小：

| 因素 | train | validation |
|---|---:|---:|
| T01−T00：C0下A改B | -0.528208 | -0.820209 |
| T11−T10：C1下A改B | -0.528418 | -0.821475 |
| T10−T00：A下C0改C1 | -0.013564 | -0.013215 |
| T11−T01：B下C0改C1 | -0.013774 | -0.014482 |
| T11−T10−T01+T00：交互 | -0.000210 | -0.001266 |

B替换在两种初值下都改善全部94个训练和27个验证航次的平均路径MSE。C1替换在两种标签下都改善91/94个训练和26/27个验证航次，其余航次没有改善。C1总体积分收益很小，交互也很小，并不存在只有联合改变才有主要改善的现象。对称MSE主效应及终点效应见 `factor_summary.csv`；不把RMS改善百分比相加，也不把数值分解解释为物理因果贡献。

积分器在首步之后使用规定的未来角速度，初始角速度直接作用于首步旋转并随后传播；未来标签则作用于整个路径。这解释了本实验中的量级差异，但不等于证明改变GRU历史表示也只有同等小影响。

C1的p初值误差在全部121个航次上增加（复用上一轮结论），r也总体恶化。因此小幅积分收益不能把C1变成优胜状态估计器。

初值至首个未来标签的三轴跳变范数均值（rad/s），T00/T01/T10/T11依次为：train 0.579324/0.568062/0.576072/0.565300；validation 0.665183/0.650571/0.670645/0.656061。T01未增大总体首步跳变，但跳变仍明显；它同时包含真实运动变化、异步观测和初值误差，不能整体解释为表示错误。逐轴有符号跳变在窗口CSV、逐轴RMS在汇总CSV。B(t0)从未替代因果初值。

## 下一步判断（Q1–Q5）

1. **主要来源是B未来标签。** 其MSE收益远大于C1替换，且全部航次方向一致。
2. **C0+B接近T11。** 两者路径RMS仅差train 0.007366°、validation 0.006813°。
3. **C1不是可靠改进方案。** A/B下总体积分略有帮助，但部分航次退化，且p初值全航次恶化，不推荐继续使用。
4. **保留C0、研究B监督合理。** 尚需处理首步初值锚定偏差以及约25%/28%窗口缺少完整未来支持的问题。不能用B(t0)偷偷替换因果初值，也不能以补零或外推实现完整监督。
5. **建议下一轮小规模比较，但先完成目标打包接口检查。** 固定M0、原Loss形式和C0/V0输入，比较C0+A与C0+B，seed17、6epoch，沿用既有航次隔离及train-only尺度规则。两臂使用相同窗口、共同有效支持掩码、预算和未加权validation选择规则；B只替换目标角速度，不进入模型历史或推理。需要预先明确部分前缀如何进入原四项Loss并在两臂保持一致，防止支持变化混淆标签效应。本轮不实施这些训练，也不选择新增Loss系数。

姿态积分更一致只说明候选监督与记录姿态更兼容，不保证自主预测、滚转方向、幅度或控制可用性改善。现有开发数据已多次用于研究设计，下一轮仍是探索性证据。
