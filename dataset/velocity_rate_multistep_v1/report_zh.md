## 时间、相位与控制契约

- 递推 dt 来自 vehicle_local_position.timestamp_sample 的真实差值；决策时间是该消息 timestamp。历史 q/ω/动作按发布时间向后保持，保存年龄与测量时间。初始 q/ω 可能早于初始 p/v；这是观测异步性，不隐式插值或用目标反填初态。
- 未来 p/v 原样保存；未来 q/ω 的离线配对只在 targets 命名空间。输入/目标测量时刻和发布时间均可追溯。四元数 Hamilton wxyz，FRD→NED，ω 为 FRD rad/s；v_B=R_NBᵀ v_N，转换时使用单位化旋转副本，原始四元数不改写。
- 17 个已标识固件的相关消息定义、AS5600 驱动、WingPhase 源文件逐提交审计，内容一致。恢复日志 target_1723_reconstructed.ulg 没有 ver_sw，不借用其他日志固件身份；其参数、字段和时间质量可检查，但 firmware_verified=false，保留为 provenance REVIEW；依赖固件发布上界证明的历史编码器相位/频率掩码为 false，原始数据与未来目标仍保留。
- wing_phase.timestamp 回填编码器时刻，并非模块发布时刻。历史输入禁止使用其值。encoder_count 与 flap_frequency 的驱动 timestamp 是采集后、发布前的时间；以同一串行驱动下一条已记录消息的时间作为前一条已发布的保守上界，只在上界不晚于当前决策时使用前一条值。没有可用上界的末条不可作历史输入。原生发布时间未直接记录的事实仍明确保留，绝不把上界称为实测发布时间。
- 相对相位由整条日志第一个编码器计数为基准计算，保留计数、基准时间、未缠绕相位和 sin/cos。窗口不重新归零；原始 wing_phase 和 Hall 原生记录保留用于目标/审计。所有日志 FLAP_RATIO≈7.90909；本实验依日志参数，不套用四月 ratio8 修正，这也不等于独立测量验证了真实硬件比或跨日志绝对翼相位零点。
- 控制顺序固定为 motor / left_elevon / right_elevon / rudder，来自 actuator_motors[0]、actuator_servos[0:3]；是分配器发布的归一化命令，非舵角实测。PWM 功能、反向与限幅参数逐日志保存。u[k] 只取发布时间≤测量 t[k] 的命令，区间内其余已记录命令作为明确提供的条件回放事件带，绝不取未来区间均值冒充 u[k]。
- 记录受日志采样率约束；不能证明日志保留了每次硬件命令更新，也不声称改变控制后的反事实动作响应已验证。模式切换与 |ω|>2rad/s 高动态保留标记。

## 划分与输入输出

日期、日志、物理飞行整体划分；9月8日、9月19日保留测试身份，新增10月13日测试；9月7日/17日及新增9月26日/10月11日验证，其余明确列于配置。恢复日志按所属日期绑定，逐原生状态指纹和 boot 身份检查跨集合重复；只读已审阅清单指定日志。测试数据按本次授权做构建/结构 QA，不训练、不据此调整阈值。不能称历史测试从未被查看。

```python
from system_identification.data.velocity_rate_dataset import VelocityRateDataset
ds = VelocityRateDataset('dataset/velocity_rate_multistep_v1',
    split='train', sampling_group='main_50hz', history_us=500000, horizon_us=200000)
batch = ds[0]
x = batch['inputs']    # history [H,20], masks, ages, initial_state [13], future dt/control
y = batch['targets']   # state [K,13], masks, next v_N/omega_B, phase/frequency targets
```

状态顺序：p_N(3)、v_N(3)、q_NB(wxyz,4)、ω_B(3)。history 另加四路控制、相对相位 sin/cos 和频率。联合或解耦模型均可切片这些通道。长度可变，下游自行按真实长度分桶或 padding+mask。只把 inputs 送入模型；未来真实状态、相位、频率只在 targets。未来 dt 是本记录的采样计划，不是模型状态特征。
递推后续状态须由模型预测反馈；本数据 API 不提供 teacher-forcing 输入。多步损失可对 targets.state 全序列的 p/v/R/ω 计算，具体网络、积分器和权重尚未固定。
归一化仅由 train 的有效原生样本计算并保存 normalization.json；没有利用验证或测试数据拟合。所有 Parquet 本地保留，源码、配置、摘要与哈希可提交。

扩展 500ms/1s/2s 的分组窗口统计、控制范围/饱和、频率和飞行工况覆盖见 quality_summary.json。已保存完整原生控制事件，窗口索引不复制数百万段重叠序列；加载器按 flight_id 惰性读取。
native 表额外保存至多两条前置、一条后置边界记录，仅供来源核对，in_reviewed_flight=false；所有训练窗口的完整信号支持区间仍须位于审阅飞行边界内。
